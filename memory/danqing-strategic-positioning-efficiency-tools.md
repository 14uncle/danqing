丹青从"通用 UI 框架 / 小游戏 UI / HIS 客户端"的探索中收敛为:

- **产品定位**:Rust 桌面小工具的轻量自绘 UI 基础设施,产品分两族——
  - **专注陪伴工具**(番茄钟、呼吸、白噪音):驻留久、密度低,**氛围即功能**
  - **效率工具**(剪贴板管理器、启动器、便签):调用频繁、扫读密集,氛围须克制(低存在感场景 + 强玻璃)
- **目标用户**:想用 Rust 写跨平台小而美桌面工具的开发者
- **视觉语言(美学方向)**:用户深爱潮汐 (Tide, io.moreless.tide) 的沉浸氛围感——**场景大图是界面主角、色调随场景流动、UI 退后极简**;玻璃表面作为大图上的可读性层保留。该美学贯穿两族产品,按族定量:专注陪伴全量沉浸,效率工具克制版。2026-07-23 用户明确"阶段 1(浅色毛玻璃)甚至可以推倒重来",浅色/深色未定
- **首个 POC**:**专注陪伴工具(番茄钟)**——设计系统的最佳验证器;剪贴板历史管理器降为第二 POC
- **性能路线**:静态预渲染模糊 + damage-based 按需渲染 + 启动/常驻占用基准

完整 one-pager 见仓库文件 `docs/ideas/danqing-efficiency-tool-glassmorphism.md`(注意:该文档写于 POC 切换前,其中"剪贴板首个 POC"已被本决策取代)。

**Why:** 场景沉浸适合专注陪伴型工具(驻留久、密度低,氛围是功能),不适合检索操作型效率工具(调用频繁、扫读密集,氛围是税)——番茄钟是前者,剪贴板是后者,故 POC 顺序对调;但两族共享同一套美学方向,只是剂量不同。框架能力与两族都高度匹配。见 [[danqing-project-state]]。

**How to apply:**
- 后续里程碑按三阶段推进:
  1. 设计系统 + 品牌视觉(阶段 1 美学可能按场景沉浸方向重做,框架/widget 逻辑保留)
  2. 专注(番茄钟) POC:场景大图 + 动态色调 + 玻璃卡片 + 计时动画
  3. 性能基础设施(启动时间、按需渲染、内存基准)
- 不做 HIS/医疗客户端、不做游戏专用组件、不做完整通用 UI 框架。
- 毛玻璃模糊先采用**静态预渲染方案**,不挑战实时全屏动态模糊。
