## 一句话裁决

**这仗能打, 但要打的不是「更好的番茄钟」, 是「桌面上的专注世界」。** 用体验层回应功能层, 该组合在功能型阵营无人占据——差异点立得住, 但有两个裂缝不改会漏气。

## 方法

interview-me 确认的比对范围与目的:

- **比对对象**: 功能型番茄钟整个阵营(番茄TODO / Forest / Focus To-Do / 桌面工具类)。沉浸型对手(潮汐 Tide、Endel 等)**显式排除**——那是另一把标尺, 若未来对标, 审美护城河须重考。
- **目的**: 定位校验——验证「审美 + 数据 + 思想史」三台复利机器在免费且功能做满的对手面前, 是否撑得起 ¥68 买断。
- **取证**: 2026-08 桌面搜索(App Store 页、评测、横评)。

## 三台复利机器检验

### ① 审美/品味 —— 立得住

功能型阵营最接近的是 Forest 的 Mindful Space 与 One Tomato 的优雅界面,但都是**静态音景/皮肤**。无人做「计时运行时世界环绕、5 种动画场景、800ms 交叉淡化、动效与环境音同源」。本标尺下审美护城河无对手。

> ⚠️ 标尺边界: 此结论成立的前提是把潮汐这类沉浸型排除在外。若未来对标潮汐,审美护城河须重考。

### ② 数据 —— 半立,裂缝在同步

统计/热力图/年报告这个"功能"已被番茄TODO、Focus To-Do 做满。danqing 的反打点不在"有没有统计",而在**所有权与开放性**: 竞品把数据锁在订阅墙后 + 云锁死(换 app=丢历史);danqing 本地优先、数据层全免费、明文可导出、格式十年演进。

**但两个注意**:
- 数据开放撑的是「切换成本」与「信任」,撑不起 ¥68——用户不为此付费。
- 番茄TODO / Focus To-Do 的**跨设备云同步已是默认能力**,danqing 数据同步未做。**单机状态下的数据护城河是空的**。

### ③ 思想史/署名 —— 唯一,不撑本期付费

无人竞争,是品牌/信任资产,作用于第 3 年+ 品牌成型期。不能单独撑起本期 ¥68。

## 定价锚点校验

功能型阵营的「终身买断」锚点被压得很低:

- **Focus To-Do**: $11.99 终身,含全平台同步 + 深度报告(≈¥85)
- **番茄TODO**: 三年卡 ¥58
- **Forest Plus**: ~$36/年

**¥68 在"功能层"上是贵的**——danqing 功能层只有 5 场景 + 基础统计,远不如 Focus To-Do 的 Gantt/报告/任务绑定。¥68 的 justify 必须**全部压在体验层**(动画沉浸世界 + 数据所有权)上才成立。

## 威胁图谱

- **高威胁**: 番茄TODO(免费体量 + 数据已深)、Focus To-Do(Windows 桌面 + 终身低价 + 跨平台同步)——压住「免费 / 桌面+买断」两翼。
- **中威胁**: Forest——证明"氛围"有市场(6 千万用户),但美学是游戏化风非沉浸风,且无 Windows。
- **低威胁**: One Tomato / 番茄钟 4.1 / 泡泡白噪音——验证"Windows + 白噪音 + 沉浸"有需求,但体验粗糙、无动画世界、无数据深度。
- **空档**: 无人占据 danqing 的组合位。

## 两个裂缝与定位修正

1. **定位措辞**: 从「番茄钟」改为「专注陪伴的沉浸世界」。竞品打功能,danqing 打世界——否则用户在 Focus To-Do $11.99 锚点下不会为 ¥68 买单。
2. **数据同步前置**: 数据复利成立的前提是跨设备积累,单机等于自废数据护城河。同步已在订阅留口计划内,优先级应前置(先有 spec,不急于建后端)。
