# Spec: 旗舰付费边界 —— 免费版 vs 旗舰版

- @author 十四叔
- @date 2026/08/01
- 状态: 已确认 (2026-08-01 用户逐项拍板四项边界; 依据 `docs/intent/companion-flagship.md`)

## 决策目标

免费版是**引流口**,旗舰版是**核心体验**。边界由两条战略原则反推:

1. **数据层免费**(喂数据护城河): 本地专注记录 + 基础统计 + 导出全免费——记录得越全,十年后用户侧数据复利越大;且开放数据降低迁移恐惧,是数据产品建立信任的前提。
2. **品味溢价收费**(变现支点): 场景、环境音、深度定制是"丹青味"的载体,抄不走也最值得付费——旗舰的核心价值在这。

**免费版不做广告、不卖数据**——数据产品信任第一,流量变现与本战略冲突。

## 免费版

| 能力 | 说明 |
|------|------|
| 基础番茄钟 | 25/5/15 计时,开始/暂停/跳过;轮次 + 长休息 |
| 自定义时长 | 专注/短休/长休步进(设置面板现有能力,不回收) |
| 1 个场景 | 篝火(默认/首个场景) |
| 今日计数 | 副标「今日 N」(现有能力) |
| 本地专注记录 | 会话历史持久化(数据层,见 `plan-flagship-roadmap.md` Task C) |
| 基础统计 | 今日/本周/累计(本地) |
| 数据导出 | CSV/JSON 明文导出(免费,开放数据) |

## 旗舰版(付费)

| 能力 | 说明 |
|------|------|
| 全 5 场景 | 海/雨/山/森林 + 篝火,全部场景动效 |
| 场景环境音 | 5 场景环境音 + 交叉淡化(环境音是专注品类门槛) |
| 统计增强 | 年度报告、深度洞察(历史沉淀的兑现) |
| 数据同步 | 跨设备同步(付费点,引入后端,本期不做) |
| 深度定制 | 默认计时方案、每场景音景开关、主题细节 |

## 付费形态(已确认 2026-08-01)

- **买断 + 订阅双轨**:
  - **买断 ¥68**: 一次性解锁旗舰(全 5 场景 + 环境音)
  - **订阅留口**: 为未来「数据同步 + 年度报告」预留,本期不上线、不做「即将推出」展示
- 免费→旗舰升级路径: 固定篝火 → 全场景 + 环境音,升级即解锁核心体验。

## 本期(里程碑 0)落地范围

- 数据层与统计**全按免费实现**,不分版(付费边界先行定义,数据不因免费而残缺)。
- 不实现任何付费门禁(无支付/激活);spec 只为边界定语义,门禁在旗舰真正上市时再加。
- 因此本 spec **不阻塞 Task C(数据层 MVP)**: 数据层照常全量收集。

## 已定决策(2026-08-01 用户逐项确认)

1. **免费场景固定「篝火」** —— 默认即入口,升级时「解锁全场景」对比最直观。
2. **自定义时长免费** —— 已有能力不回收,免费版体验完整性靠它。
3. **买断 ¥68 + 订阅留口双轨** —— 买断解锁旗舰;订阅为未来「数据同步 + 年度报告」预留。
4. **订阅留口本期不做展示** —— 专注打磨核心体验,订阅待数据同步真正上线时再做。

## 遗留(非本期)

- 付费门禁(支付/激活/订阅)未实现——spec 只为边界定语义,旗舰上市时再加。
- 数据同步后端未建——订阅上线的前置。
