# Spec: 星夜场景银河升级 — 深邃银河(三层合成)

- @author 十四叔
- @date 2026/08/03
- 状态: 待评审
- 上位意图: `docs/intent/scene-atmosphere-upgrade.md`(2026-08-03 用户显式 yes)

## Objective

2026-08-03 用户终审诊断:星空场景**单调,要深邃银河**。根因:现星野为 48×28 均匀 hash 格、仅 ~100 颗星(当年为对齐旧静态图密度所定),无主体、无结构、无密度起伏。

本 spec 在**统一 AI/程序化血统**下为星夜加银河主体,三层合成:

1. **AI 重画底图** — 银河光带 + 尘埃暗隙(构图层)
2. **真实星表亮星层** — Yale BSC(9,110 颗 ≤6.5 等)提供真实星座结构与密度起伏,替换均匀 hash 网格
3. **程序化暗星雾层** — 沿银河带聚集的高密度 hash 暗星,补足 BSC 亮星给不了的"深邃"体量

用户: 番茄钟使用者(单一用户即作者本人)。成功 = 银河带一眼可辨、亮星有真实星座结构、星闪/暂停语义零回归、与海/雨并排盲切不输、性能门槛不破。

**统一血统约束(意图层,永久有效)**: 不引入任何外部图库/照片/视频资产;星点真实密度来自**天文数据**(数据驱动生成与 shader 生成同宗),不来自照片。

## Tech Stack

- Rust + wgpu 30 + winit 0.30(同主仓);渲染改动集中在 `src/render/background.wgsl` 与星夜纹理烘焙。
- 预处理: `tools/` 新增 Python 脚本(对齐 `export-scenes.py` 惯例),Yale BSC 星表 → `assets/stars.bin`。
- **uniform 布局不动**(11×f32/48B):银河层挂 `starry_base`(常驻,暂停定格),星闪挂 `starry_intensity`(包络沉降),`motion.rs` 策略层零改动。

## Design

### 资产层 1: AI 重画星夜底图(构图契约)

现底图: 深靛蓝夜空渐变 + 底部两层暗山脊,无星点(2026-08-01 裁定)。重画后在保留山脊的前提下加银河:

- **光带走向**: 左下 → 右上斜跨,避开中央倒计时大字区;最亮段(银河中心方向)压在上三分之一。
- **灰度防线(防穿帮)**: 底图**不许可分辨亮星**——可分辨亮星一律来自运行时层(烘焙星不闪=穿帮);允许不可分辨的星点雾作为银河质感。可分辨阈值(像素尺寸/亮度)在生图迭代时由用户裁定,生图多轮挑片是预期成本。
- **山脊剪影原样保留**;调色板 base (22,26,52) 不变。
- 底图经 `tools/export-scenes.py` 重新生成(`scenes.rs` 为生成文件,不手改)。

### 资产层 2: 星表预处理(tools/export-stars.py → assets/stars.bin)

- **星表**: Yale Bright Star Catalog(9,110 颗,视星等 ≤6.5)。授权已尽调确认(2026-08-03,见 Open Questions);数据源 `ybsc5.gz`(ASCII),**自带 GLON/GLAT 银道坐标与 B-V 色指数**——投影免坐标转换,色指数可直接服务星点暖色分布。
- **投影在银道坐标系做**: 银经 l → UV.x,银纬 b → UV.y,整体旋转一个常量角对齐底图光带。**这是关键设计**——银道坐标下亮星天然沿 b≈0 聚集,与暗星雾 mask、底图光带共用同一坐标系,对齐只需调一个旋转角 + 平移,不做真实地点/时刻地平坐标换算(不过度工程)。
- **二进制格式**: 每星 6B(x: u16, y: u16 归一化;mag: u8 量化;保留: u8),全表 ~53KB。Rust 侧 `include_bytes!`。
- `assets/stars.bin` 是 assets/ 首个**数据资产**(非视觉资产),意图文档已授权。

### 渲染层: 启动烘焙 + shader 重写 star_field

- **CPU 启动烘焙**: 星表 → 单通道星野纹理(1280×720 R16F 或 Rgba8 复用现有通道约定),亮星按星等映射尺寸/亮度(6.5 等极限星 = 1px 弱点,亮星带小光晕)。纹理常驻(~4MB,预算内无感),烘焙耗时目标 <100ms,计入 ≤1s 启动门槛实测。
- **star_field 重写**: 采样星野纹理 × `starry_base`,替换 48×28 网格 hash(SF_COLS/SF_ROWS/SF_ON 等旧常量退役)。
- **star_twinkle 改造**: 脉冲逻辑不变(1/8 Hz 整数倍档位、`u.time`、±SF_TWINKLE_AMP 双极),但明灭改为**调制采样到的星野纹理**——细网格 hash 产生逐格脉冲场,网格密度保证每格 ≤1 颗亮星即读作逐星星闪。无需相位通道,单纹理足够。
- **star_haze 新增**: 程序化暗星雾(细 hash 点,极低亮度),密度按**银纬解析 mask**(b≈0 聚集,常量带宽)聚集;挂 `starry_base` 常驻,不闪——它是"深邃"的体量来源。
- **meteor 不动**。
- 银河带解析 mask 的角度/宽度常量: 底图生成后**人工测量光带中心线回填**(落地步骤之一,写进 tasks)。

### 性能

- 每帧成本: 1~2 次纹理采样替换网格 hash 计算,持平或更低;无逐星循环。
- 窗口隐藏零渲染成本(架构事实,不动)。
- 启动: 解析 ~53KB + splat 9,110 点,实测不破 ≤1s。

## Testing Strategy

- **纯逻辑单测**(example 侧,无 GPU): stars.bin 解码(星数/星等分布/边界剔除)、银道投影(已知亮星落点抽验,如织女、牛郎落银河带两侧)、银纬 mask 函数(带内密度 > 带外)、uniform 护栏原样通过。
- **回归**: 既有星夜策略/接线测试全绿(常量退役引起的编译错误逐一落定);雨/火/海/山/森林零回归。
- **目测终审**: 运行 + 暂停语义;**与海/雨并排盲切不输**(意图层钉死的方法学)。

## Boundaries

- **Always**: 提交前 `cargo fmt` + 两个 clippy + 全部测试绿;星夜效参数集中在 wgsl 常量段;视觉迭代遵守 **5-commit 预算**(同区域超 5 commit 未收敛 → 提级换范式,非调参);纯逻辑留在 example 侧。
- **Ask first**: 星表授权尽调结果若不干净(启动降级:仅用星座结构自绘位置);新增依赖;银河带角度/宽度常量超出 spec 区间;底图"可分辨亮星"阈值裁定。
- **Never**: 引入照片/外部图库/视频资产(意图层永久关闭);周日视运动旋转(光带烘焙不可转,星点转=穿帮);改 uniform 布局;底图烘焙可分辨亮星;改 `motion.rs` 策略语义;手改 `scenes.rs`;为动效改变重绘频率;给星夜加独立 clock。

## Success Criteria

1. 银河光带一眼可辨(斜跨天空、有尘埃暗隙层次),与倒计时大字区无遮挡冲突。
2. 亮星分布非均匀、对照真实星图可辨星座结构(织女/牛郎隔带相望为抽验锚点)。
3. 暗星雾沿银河带聚集,"深邃"体量可感(对比升级前截图,密度分级肉眼可辨)。
4. 星闪发生在星表亮星上;暂停 500ms 星闪/流星沉降、**星野(含银河层)定格可见**——潮汐语义零回归。
5. 雨/火/海/山/森林五场景零回归(既有测试全绿 + 目测)。
6. benchmark PASS: 暖机启动 ≤1s(含星表烘焙)、常驻 WS ≤360MB。
7. **与海/雨并排盲切,至少不输**(用户终审,意图层验收方法学)。
8. 提交门槛全绿(fmt / clippy×2 / test×2)。
