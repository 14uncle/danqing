# 丹青 番茄钟打磨三件套 — 规格

> 2026-07-27 经 interview-me 对齐确认。竞品对照(潮汐 / Forest / Session / Focus To-Do, 2026 格局):
> 环境音已是品类门槛("table stakes"), 丹青番茄钟的场景沉浸目前只有视觉一半;
> 长休息节律与今日反馈环是陪伴感的缺失半环。本次打磨把 POC 从"可用"推向"日常好用"。
>
> 已确认的意图:
> - **Outcome**: ① 5 场景环境音 ② 长休息 + 轮次 ③ 今日完成计数
> - **Success**: 日常使用中听着场景音走完完整 4 轮节律, 一天结束能看到「今日 N 个」; 性能门槛不破
> - **Constraint**: 启动 ≤1s、常驻 WS ≤360MB; 音源 CC0 可提交 git; 纯逻辑层不碰平台 API
> - **Out of scope**: 干扰阻断 / 任务管理 / 云同步 / 设置 UI / 自定义时长 / 历史周报 / 音乐融合

## WS1 场景环境音

### 范围

5 个场景(篝火 / 海 / 雨 / 山 / 森林)各配一段无缝循环环境音, 随场景切换与视觉同步交叉淡化; 计时暂停时音量淡出, 恢复时淡入。

### 架构决定

- **管线选型**: `rodio` (纯 Rust 解码 + cpal/WASAPI 输出), 仅作为 example 的 dev-dependency, 不进框架层 (`src/` 零改动)。
- **资产**: `assets/audio/` 下 5 个 OGG Vorbis, 每个 ≤2MB, 无缝循环; 来源为 CC0 / 可再分发免版税库, 同目录附 `ATTRIBUTION.md` 记录每段音源的出处与许可。
- **分层**: `ambient.rs` 拆两层——
  - `AmbientMixer` 纯逻辑: 场景音量对 (from/to 随 fader 进度插值) + 暂停沉降曲线, 注入 `now` 驱动, 可单元测试;
  - rodio 输出适配层: 每场景一条循环 `Sink`, 每帧应用 mixer 算出的音量。Sink 的 `set_volume` 即交叉淡化的执行端, 无需自写采样混合。
- **淡化同步**: 音景交叉淡化时长 = 视觉 `FADE_DURATION` (800ms), 直接复用 `SceneFader::frame()` 的 `(from, to, t)`。
- **暂停沉降**: `timer.is_running() == false` 时 300ms 线性淡出至 0, 恢复时 300ms 淡入 (专注与休息一视同仁, 只看 running 状态)。
- **懒初始化**: 音频输出流在首次需要发声时才打开, 不阻塞启动路径; 设备不可用 / 文件缺失 / 解码失败一律静默降级 (记 `log::warn`), 视觉功能不受影响。
- **流式解码**: OGG 走 `rodio::Decoder` 流式, 不整段载入内存, 守住 360MB 门槛。
- **完成提示音不变**: 阶段流转仍用 `MessageBeep` (系统通道, 与环境音不冲突), 本次不引入铃声资产。

### 验收标准

- [ ] 5 场景均有环境音循环播放, 循环点听不出接缝 ⏳ 人工审听
- [ ] 场景切换时音景随画面同步 800ms 交叉淡化 (前/后按钮均生效) ⏳ 人工审听
- [ ] 暂停时 300ms 内音量淡出至无声, 恢复时淡入; 视觉降饱和与听觉沉降同时发生 ⏳ 人工审听
- [ ] 音频设备被占用 / 拔出耳机 / 音源文件缺失时应用不 panic, 视觉功能完整 ⏳ 人工降级路径验证
- [x] `tools/benchmark.ps1` 启动 ≤1s、常驻 WS ≤360MB 门槛不破 (2026-07-28: 693.8ms / 177.5MB)
- [x] `assets/audio/ATTRIBUTION.md` 记录全部音源出处与许可
- [x] `AmbientMixer` 纯逻辑单元测试: 淡化插值、暂停沉降、边界 (单场景/首尾切换)

## WS2 长休息 + 轮次

### 范围

补全番茄工作法核心节律: 每完成 4 个专注进入 15 分钟长休息; UI 显示当前第几轮。

### 架构决定

- **`Phase` 新增 `LongBreak` 变体** (15 分钟), 序列化兼容: 旧 JSON 无此值, 正向无影响。
- **轮次计数**: `Pomodoro` 内新增 `completed_focus: u8` (0..4); 专注阶段**自然完成** (tick 越过 deadline) 时 +1, 满 4 时下一阶段为 `LongBreak` 且计数归零。
- **skip 不计完成**: 手动跳过专注不进轮次计数、不进今日计数 (防刷, 语义干净); skip 出 LongBreak 与 skip 出 Break 行为一致。
- **reset 语义**: 回 Focus Idle, `completed_focus` 归零; 不影响今日总计数。
- **持久化**: `PomodoroState` 新增 `completed_focus` 字段, `#[serde(default)]` 兼容旧配置文件。
- **UI**: 副标追加轮次信息, 如 `专注 · 篝火 · 第 2/4 轮`; 长休息阶段 label 为 `长休息`。
- 全部逻辑在 `examples/pomodoro/timer.rs` 纯逻辑层, 不读 wall-clock, 完整单元测试。

### 验收标准

- [x] 连续完成 4 个专注后进入 15 分钟长休息, 长休息结束回到专注且轮次重新计数
- [x] 第 1~3 个专注完成后仍为 5 分钟短休息
- [x] skip 专注不推进轮次计数; reset 清零轮次
- [x] 旧版配置文件 (无 `completed_focus` 字段) 正常加载
- [x] 副标显示当前轮次; 长休息显示 `长休息`
- [x] 单元测试覆盖: 4 轮进长休息、长休息时长、skip/reset 语义、持久化往返

## WS3 今日完成计数

### 范围

专注阶段自然完成计 1 个番茄, 按本地日期累计, 跨重启持久化, UI 轻量展示「今日 N 个」。

### 架构决定

- **计数时机**: 仅 `tick` 自然越过 Focus 终点时 +1 (与轮次计数同一触发点); skip 不计。
- **本地日期**: 复用已有 dev-dependency `chrono` 的 `Local::now().date_naive()` (补完阶段已引入, 不新增依赖); 归零判定为纯逻辑函数 (输入上次日期串与计数), 可单元测试。
- **跨日归零**: 启动加载与每次计数前比较日期, 日期变更则 `today_count` 归零。
- **持久化**: `PomodoroState` 新增 `today_date: String` (YYYY-MM-DD) + `today_count: u32`, 均 `#[serde(default)]` 兼容旧配置。
- **UI**: 副标行追加 `· 今日 N`, N=0 时不显示该段 (首日无噪)。
- 日期换算与归零判定为纯逻辑函数 (输入 wall-clock 秒与上次日期串), 可单元测试。

### 验收标准

- [x] 专注自然完成, 今日计数 +1 并持久化; 重启后计数仍在
- [x] 跨本地日期启动, 计数归零重新累计
- [x] skip 完成专注不计数
- [x] 副标在 N≥1 时显示「今日 N」
- [x] 旧版配置文件 (无两个新字段) 正常加载
- [x] 单元测试覆盖: 计数触发、跨日归零、持久化往返
