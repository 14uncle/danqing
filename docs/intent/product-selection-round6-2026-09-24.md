## 任务定义（保护项，勿丢）

- **Outcome:** 在 log 人工审核空窗期跑第 6 轮产品选型，**产出至少一个过闸候选**——不接受「过程跑完零候选也算值」。

- **Why now:** log v1.x 编码收口进人工审核（A–F 组待实机），agent 侧空窗带宽不想浪费；**无新市场扰动**（log 共振数据出现后用户仍选造物，非扰动驱动）。
- **Success:** 捞到 = 候选同时过 **痛点三闸**（≥3 来源 + 行为证据 + 付费行为证据单列 + 失效标志）× **准入三问**（渠道可达 / 在场质检 / 缝隙三条判据）× **需求侧双半验证**（替代侧 + 需求侧），且带**裁决段**。

- **处置:** **开工许可证**——过闸候选可直接进 spec / 建仓；log A–F 组人工验收（用户侧）并行不被挤掉。
- **Out of scope:** 分发**不加注**（09-28 回读、10-18/10-21 校准钟按台账照走=记账不是加注）；本轮**不写产品代码**；不复活任何已埋产品（clipboard 商业化 / xirang / disk / tile 保持坟头）。

## 本轮产生器：全付费品类反转普查（付费独占缝）

前两代产生器的结构性教训：**供给侧找「死掉的免费」产出位置不产出需求；需求侧挖抱怨必然落进已争夺市场。** 本轮反转——**不找僵尸，找「付费在位者独占、免费 catcher 缺位」的品类**：

- 理由一：round5 唯一候选（分镜）正是此型（付费在位者真 + 免费缺位 + 公司弃坑）——把「唯一产出型」升格为主产生器。
- 理由二：指南许可条款（2026-09-15 澄清）——**有付费竞品是最强行为铁证**（有人掏钱），纯空白反而是渠道挂科风险；付费独占缝同时自带付费行为证据。
- 理由三：「免费 catcher 缺位」把 tile/clipboard 死因（免费例外封死）作为**产生器的前置条件**而非后置检查，产出即免去第一杀手。

**反转普查五问（全过才立候选）**：
1. 品类主力工具**全付费/订阅**（≥2 个在位者且有真实购买行为铁证：销量/评分量/续费讨论）
2. **免费 catcher 缺位或结构性残疾**——穷尽查证「有没有人（任何人）免费做这件事」（tile 教训：盘点必须穷尽）；玩具级/停更免费方案单独注明状态+证据日期
3. **需求侧证据**：≥3 独立来源 + 近两年内 + ≥1 处行为证据（付费/续费/迁移/手工凑合，权重 > 言词抱怨）；**付费意愿行为证据单列**；查需求衰减 = 看帖子/issue **创建日期分布**不看总票数
4. **需求迁移检查**：增量人群工作流是否正被 AI 管线/邻近管线接走（round5 C1 死因），看增量人群形态不看存量钉子户
5. **载体可为 Windows 桌面 GUI**（danqing 肌肉；不做协议逆向深水区/内核驱动/取证深水区——实现约束挂过两次）

候选卷子（普查产出后逐条补）：痛点三闸 × 准入三问（含闸③三条：在位者动向带证据日期 / 结构能否跟进 / 盘点穷尽）× 双半验证 + 失效标志 + 一页粗算 + 裁决段（归用户）。

**在场质检边界（域的硬约束）**：只扫「造物主读得懂抱怨、判得出方案好坏」的域——开发者工具、创意/生产工具、通用办公/数据。**明确不做**：医疗/HIS（CLAUDE.md 排除）、游戏专用组件（排除）、深专业工程垂直（暖通/电气/药学/金融合规——质检闸挂）、协议逆向深水区。
