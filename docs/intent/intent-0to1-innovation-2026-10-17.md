# 0→1 开创性产品方向 · 意图与候选池（2026-10-17）

> 状态：候选池已落盘，**不开枪不动当前队列**（组合纪律照卡：Drop Shelf / Luoban / Plainsight / log v1.x 不受影响）。
> 本卷是 round10+ 的选型弹药库。开枪前逐案走调研三闸（裁决段 + 红队 + 粗算）。

## 一、题目书（interview-me 确认稿，2026-10-17 用户逐行确认）

- **Outcome:** 一份 0→1 产品方向清单——开创新品类/新交互关系的惊为天人方案，不是给现有产品缝补丁
- **User:** 农场选型弹药库（round10+ 的候选池），替换「价值不大」的现有缝补批
- **Why now:** 现有筛选产物全是同类补丁；LLM 把可能性空间撑开了，值得把想象力拉满重开一轮
- **Success:** 每个方案能过入场券——「谁还在凑合」铁证，**或** 心法二培养路线（现象起点 → 书面推理链 → 失效标志写死）；且开创性上「第一次见的交互/品类」必须立住
- **Constraint:** 解决用户需求是唯一硬锚；danqing 复用是软条件（能用则加分）；变现/渠道围栏本轮不作否决理由，留给开枪前的调研三闸去裁
- **Out of scope:** 不开枪不动当前队列（组合纪律照卡）；不照搬 OpenClaw 形态；不做纯许愿清单（无现象无推理链的点子不进清单）

### 开创性判定（本卷专用裁决，勿与已废除条款混淆）

- 双条件：**「LLM 之前这产品根本不成立」×「第一次见的交互/品类」**，后者权重更高。
- 「惊为天人」评的是**可能性边界的突破**，不是 09-05 已废除的「灵魂/感动」（那条评情感浓度，已死，不回归）。
- OpenClaw 只是量级参照（开创性该有多惊），不是形态参照（不照搬常驻 agent/消息平台形态）。

## 二、倒推逻辑

**LLM 把「人肉胶水」这个岗位取消了。** 人过去一直在给机器当翻译、当记忆、当跑腿、当户口警。凡是有「胶水人」的地方，就长得出新品类。

现象旁证先用常识层的，**带日期的铁证留到开枪前调研三闸核验——不编日期**。

## 三、候选池（六案，按注序排列）

### 1. 物格 · 万物户口 ——「你家的东西终于会说话」

- **现象起点:** 说明书塞抽屉归档（土法仪式）、保修单找不到、滤芯型号靠拆机看铭牌、闲鱼转卖时拍说明书证明参数、子女远程问「我妈这堆药能不能一起吃」。胶水人 = 给实物当户口警的人。
- **推理链:** 现象 = 人在手工给实物建档 → 本质 = 实物没有数字分身，信息熵全压在人脑和抽屉里 → 什么在变 = VLM 一拍建档、自然语言问答白菜价 → 方向 = **实物户口本**：拍照入籍，从此「问它」而不是「查它」。
- **LLM 前不成立:** 认型号、读说明书、答「这台该怎么办」全靠人肉。
- **开创性:** 第一次见**物品成为对话主体**——不是记录软件，是家里每件东西有了可问的分身。品类名没出现过。
- **失效标志:** ① 手机厂商/电商把「扫物 = 档案 + 问答」做成系统级 checkbox（吸收）；② 实测建档惰性——用户不愿为一件东西花 3 分钟拍照建档，弃用率 >70%。
- **danqing 复用:** 高。图册/时间线/结构化台账是自绘 UI 主场。
- **风险:** 冷启动惰性；型号/保修数据源。

### 2. 仪式 · 徒弟 ——「演示三遍，电脑出师」

- **现象起点:** 每天「导出-改名-贴群」、每周报表拼装、发票重命名归档。**按键精灵/Quicker/简道云养活一个品类 = 凑合的铁证**（付费行为级）。
- **推理链:** 现象 = 人自己在当 API，手工搬运数据 → 本质 = 跨软件意图没有表达语言，只能人肉执行 → 什么在变 = LLM 看懂屏幕语义，宏从「坐标回放」变「意图复述」→ 方向 = **教徒弟**：演示三遍，它复述成你可编辑的仪式，之后代你执行。
- **LLM 前不成立:** 按键精灵是坐标级回放，界面改版即死。
- **开创性:** 交互关系第一次见——从「配置自动化流程」变「**带徒弟**」。人机关系变了，不只是效率变了。
- **失效标志:** ① Windows / Power Automate 把「语义化录制」做成系统 checkbox（**本清单吸收距离最近的，要死盯**）；② 实测仪式失败率 >20%，用户不敢放手让它跑；③ 通用 computer-use agent（Claude Code/OpenAI Operator 这类）下场做非程序员市场——终局杀手（2026-10-17 红队补）。
- **danqing 复用:** 中高。仪式编辑器/执行可视化。
- **风险:** 吸收距离近。

### 3. 权衡 · 主张器 ——「把吃过的亏要回来」

- **现象起点:** 拖欠工资、押金不退、假货拒赔——吃哑巴亏是国民现象；土法 = 搜「被迫离职通知书怎么写」、小红书维权攻略内容产业、求懂法的朋友。**攻略帖的繁荣就是凑合的铁证**。
- **推理链:** 现象 = 人吃小亏不主张 → 本质 = 主张成本（懂法 + 文书 + 流程）远高于吃亏额 → 什么在变 = LLM 把「懂法 + 写文书」成本打到白菜 → 方向 = 贴聊天记录/合同，输出「你可以主张什么 + 话术 + 流程」的**主张执行器**。
- **LLM 前不成立:** 律师咨询起步价几百，没人为了 500 块押金找律师。
- **开创性:** 第一次见「吃亏 → 主张」的自助流水线。品类名不存在。
- **失效标志:** ① 被认定为变相法律执业、监管掐死；② 实测主张意愿为零——怕麻烦的人拿到方案也不动，工具变安慰剂。
- **danqing 复用:** 中。文档/对照视图。
- **风险:** 监管敏感；付费形态要小心（买断卖工具 OK，分成/订阅撞奶牛禁令）。

### 4. 办事 · 预演台 ——「跑窗口之前先跑一遍」

- **现象起点:** 居住证/营业执照/生育津贴——小红书「办理攻略」人肉知识套利、跑三趟窗口、材料清单靠打电话问。攻略帖 + 代办黄牛 = 双重凑合铁证。
- **推理链:** 现象 = 办事靠攻略帖和跑断腿 → 本质 = 流程暗知识「只有跑过才知道」→ 什么在变 = LLM 能把暗知识变成预演（清单核验 + 表格草稿 + 模拟问答）→ 方向 = **事前预演**取代事后补救。
- **LLM 前不成立:** 暗知识靠人肉传，攻略一过期就骗人。
- **开创性:** 第一次见「办事预演」这个环节本身。
- **失效标志:** ① 政务一网通办把智能预审做成 checkbox；② 信息时效性崩盘——预演说能办、窗口说不行，信任一次性死掉。
- **danqing 复用:** 中。表单/清单视图。
- **风险:** 政务信息碎片化维护成本；错误信息的责任问题。

### 5. 传家 · 采访员 ——「替你采访爷爷」

- **现象起点:** 「后悔没给爷爷录下来」叙事、口述史志愿活动、修谱热。走**培养路线**（现象偏叙事、偏弱，如实标注）。
- **推理链:** 现象 = 老人故事带进坟墓，子女想录没时间也不会问 → 本质 = 采访是专业 + 时间活，门槛挡住了孝心 → 什么在变 = LLM 会追问、会倾听、永不疲倦 → 方向 = 发起一次「对话工程」，AI 当采访者，产出会讲故事的家族档案。
- **LLM 前不成立:** 会追问的采访者是稀缺专业人力。
- **开创性:** 第一次见 **AI 作为家族记忆的采集者**——不是录音笔，是会追问的晚辈。
- **失效标志:** ① 子女实际发起率 <10%（孝心不落地，培养失败）；② 老人对机器没话说，采集质量差。
- **danqing 复用:** 高。档案展示是自绘 UI 强项。
- **风险:** 冷启动靠情感动员 = 分发难（农场的真约束）；采集端偏移动。

### 6. 屏幕 · 自传 ——「你的一周自己写出来」

- **现象起点:** 自由职业者工时回忆记账、打工人周报靠翻聊天记录、RescueTime 只有分类没有意义。工时表/周报 = 全人类土法仪式。
- **推理链:** 现象 = 劳动成果要靠人肉回忆补记 → 本质 = 屏幕上的劳动没留下语义记录 → 什么在变 = 屏幕语义理解 + 叙述生成 → 方向 = 机器替你写「时间去哪了」的**意义层**叙事。
- **LLM 前不成立:** 只能记时长，不能记意义。
- **开创性:** 第一次见意义层的屏幕记忆（Recall 是快照，不是叙事）。
- **失效标志:** ① **Microsoft Recall 系统吸收——本清单最近的第二家**；② 隐私恐惧实测无人敢开。
- **danqing 复用:** 高。
- **风险:** 吸收 + 隐私双杀。

**初排：1（物格）> 2（徒弟）> 3（主张器）> 4（预演台）> 5（采访员）> 6（自传）。**

## 五、刻意排除的尸体（防误以为漏了）

- **对话考古 / AI 工作史**——OpenClaw 邻接，形态照搬嫌疑，违反 Out of scope。
- **智能摘要 / 问答搜索**——纯缝补，不达开创性线。

## 七、红队四刀 · 吸收距离重审（2026-10-17 当日，用户逐刀发起）

> 触发：用户质疑「DeepSeek/元宝/豆包 都多模态了，还有存活的吗」。四刀砍完，幸存论题收窄为一个三角。

### 第一刀 · 通用多模态助手（DeepSeek / 元宝 / 豆包）

**吸收边界（本轮最重要的产出）：只「答」不「管」、只「说」不「做」、无户口。** 「惊为天人」的产地必须避开感知层——任何靠「它能看懂/会说话」当卖点的点子全灭，wow 要去关系层/持久态层找。

| 案 | 被吸收的 | 存活的骨架 | 一轮判决 |
|---|---|---|---|
| 1 物格 | 「拍照问它」——headline「会说话」死 | 户口本：保修倒计时/台账/家庭共享 | 存活，惊为天人论证重写（wow 在「有户口」不在「会说话」） |
| 2 徒弟 | 无（助手停在「说」） | 教会-复述-代执行 | 存活 |
| 3 主张器 | 单次文书生成 | 案件管家：证据链/时效/跟进 | 重创，缩成「跟单」 |
| 4 预演台 | 「要什么材料」问答 | 官方源核验+预填+跟单 | 重创，残余更像功能 |
| 5 采访员 | 「会追问的聊天」 | 采访工程：多场计划/成书 | 部分吸收，骨架在 |
| 6 自传 | 「写周报」用例 | — | 濒死 |

### 第二刀 · 办公 AI 同事（WorkBuddy 类目）

吃「做」的标准化半区（连得上的办公三件套/云生态），补刀 6。吃不掉：本地长尾软件（国内烂内部系统/网银插件/报税客户端）、私人域、非标怪癖仪式、主权/买断。**2 徒弟滩头换址：从「办公自动化」挪到「长尾软件之间的摆渡人」。**

### 第三刀 · 程序刀（Claude Code）

不做竞争者谈（受众是程序员），**当证据谈：Claude Code = 「做+管」× 本地长尾的活体证明**——执行型 agent 落专精域+本地是立得住的品类，且人们肯付费。徒弟 ≈ Claude Code 同构物换域（代码→长尾办公软件）。终局哨兵：Claude Code 架构通用，「走出代码域」只差产品定位一步——已记入案 2 失效标志③。

### WorkBuddy 实测修正（官网 bundle 原文，2026-10-17 抓取）

- **真身:** 腾讯云 CodeBuddy 团队出品。「全能 AI 工作台，一人指挥，全行业专家执行，从需求到交付一站搞定」；多 Agents 并行、专家+技能+连接器、个性化记忆、跨文件理解、**启动终端执行**、自动化任务、OpenAPI、多端协同（含微信小程序）；产出=报告/PPT/表格成品。**订阅+积分制**（Free 100 积分/Pro $10 月·$8 年付/企业版），自动化任务限额 3–15 个/月（限免 99）。
- **重判 2 徒弟：从「开创性品类」降为「缝隙战机」。**「指挥官-专家」范式已先发布，自动化任务被按积分收租。残余卖点只剩三角（见下）。开创性叙事不重写就是抄腾讯。
- **现象级铁证：** 腾讯用积分墙卖「替你跑腿」——需求被巨头验证，只是被租着卖。
- **零伤确认：** 1 物格（腾讯记忆是工作域，家庭实物户口是私人域，企业销售压力会把腾讯锁在办公域）；5 微伤。

### 第四刀 · key 墙（分发层判决，用户发起）

「普通用户大多不会申请 API key」——**主权三角的门票 = 配置门槛，幸存象限不是免费的。**

- **死路钉死:** 农场代买 key/托管推理 = 零后端死 + 计量收费 = 积分墙 = 奶牛禁令毙 + 单人运维地狱。**「LLM 大众产品」×「买断零后端」的互斥是真的，没有第四条路。**
- **活路三层叠（不是三选一）:**
  - **A. prosumer（BYO key）**——OpenClaw 已全球公测；买家≠用户翻法：「家里懂电脑的那个」买断装好，全家当户口主。
  - **B. 端侧小模型当无 key 路径**——懒下载量化小模型（认铭牌/读日期够用）；NPU/端侧硬件是上坡路；主权最纯（推理都不出门）。
  - **C. 核心体验去 LLM 化**——户口本体零门槛可用，AI 层是可选增强。
- **逐案硬约束:** 1 = 核心体验零 LLM 化（天生抗 key 墙，排名不降）；5 = 采集端零配置（靠「子女设置好」+端侧硬扛）；2 = prosumer 色彩，A 路伤害最小但分发更难。

### 四刀后终排与存活条件

**终排：1（物格）> 5（采访员）> 2（徒弟·缩滩版）> 3（案件管家）> 4（跟单版）≈ 6（判死）。**

幸存论题定稿：**买断 × 数据主权 × 私人域** 三角。大厂结构性做不了：它们靠积分订阅活（做不了买断）、靠云活（做不了主权）、被企业单锁在办公域（进不了私人域）。农场「买断=零后端架构强制」由经济学升格为**反吸收装甲**。「本地」一词作废，换「数据主权」——出门的只有推理瞬间的最小上下文，去哪家模型由用户挑，**「出门可见」当信任卖点**（家族语法「截断可见/行数可信」的 LLM 时代新刀刃）。

## 八、架构约定草案（农场级，首次引入推理依赖，待用户裁）

现有四件产品全零 LLM；候选池若开工，是产品线第一次引入推理依赖，需立约定，不许各产品自己发明：

1. **key 管理:** BYO key，key 只存本机（参照 Paddle key 仓库外管理法的心智），不进仓库不进聊天。
2. **最小上下文:** 推理请求只带瞬时必要上下文，日志本地留底。
3. **出门可见:** 发给了模型什么，用户可翻——信任卖点也是调试工具。
4. **端侧降级:** 无 key/断网走端侧小模型或纯手动，核心体验不塌。
5. **不做倒爷:** 不卖积分、不托管推理、不做模型转售（奶牛禁令的推理版）。

## 九、裁决段（2026-10-17 深度调研流水线 · 调研三闸闭合，待用户点头生效）

### 案 1 物格 · 万物户口：**转向**（当前案形不许进 spec）

需求存在性为真（行为铁证 + 评论区付费实证 + App Store 8 款井喷），但红队三颗炮弹命中：物理凑合（¥15 收纳册）被证明够用、「户口」是自造隐喻（品类语言不存在）、Windows 桌面主场可能是形态错配。粗算月流水 ¥30–300，收入不成立。

**进 spec 前五条件**：①打赢 ¥15 册子（增量价值有行为证据）②假门测试 100 UV 留邮箱 ≥2%（<2% 直接放弃）③书面回答「为什么拍照建档在电脑上做」④剩余半痛感量化 ≥3 独立来源 ⑤对外换用户语言（「家庭实物台账/档案」，「户口」降为内部隐喻）。
**放弃触发**：假门 <2% / 华为·苹果·京东上线跨品牌保修+维修史台账 / 小艺记忆推出结构化「家庭物品」模块。

### 案 2 仪式 · 徒弟：**归档**（三条复活钥匙）

需求存在性为真，但付费行为证据**全部在企业 RPA 侧**，个人买断位的空位可能是没水；核心卖点「改版不死」的痛点原话无铁证；「仪式资产」叙事被判品类错配（企业合规词汇）。三条承重墙待补 ≈ 重做一轮调研。

**复活钥匙（三条同时满足才回炉，缺一不复活）**：①≥2 条「界面改版宏失效」行为级原话 ②≥1 个个人买断 GUI 自动化付费先例（¥20+ 档）③PBD 空位定向核验（无先发布且无尸体）。
**遗产保留**：OSWorld 20.6% 脚注、「仪式资产 vs live agent」框架、长尾 GUI 合规盲区结论。

### 机制裁决（双案共杀的免死金牌，封堵）

红队炮弹 3 成立：**「资产/锻炼记账」不得当入场券，只当同分决胜**。十年愿景「产品=锻炼器材」不推翻——锻炼是收益项不是准入项；心法一的入场券（需求铁证）不可被记账替代。「粗算不得否决」只保护**有铁证**的需求不被收入误杀，不保护**缺铁证**的产品靠记账续命。以后每案裁决段必须先过入场券，再谈锻炼价值。
