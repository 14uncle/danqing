## 第一棵树：danqing-log 树种鉴定

四条树形特征它都有（配当长线资产的物种）：

1. **离 OS 的 checkbox 远**（系统吸收距离，同日入调研三闸）——clipboard/tile 没长成就被系统吸收死，log 是专业工具，Windows 不会顺手做掉它；
2. **需求耐久**——只要还有软件就有日志，不存在「被 AI 接走」的近期路径；
3. **有 10x 长板**——GB 级 mmap 秒开（Sublime 尺子量得过的那种）；
4. **零边际成本**——种下去不浇水也不会死（与 Ditto 同构）。

但「它是第一棵结果的树」**不归种树的人宣布，归三只钟**。当前真实状态：树苗存活、未挂果（陌生人首单 0，收银台未开）。

更深一层：**农场第一棵多年生作物其实是 danqing 框架本身**——它是土壤和砧木，产品是嫁接枝。clipboard「死」了，四块肌肉留在引擎里；log 这九个月长出的 checkbox / RowList / toast / 选区分词，全在土壤里。**农场的复利单位是引擎 + 判断力，产品只是锻炼器材。** 死树不心疼：每条失效的枝都是堆肥——round6/7/8 连灭三轮换来 09-25 心法重写，那是判断力资产，跟着农场走十年。

## 四层资产（十年后真正要的东西）

| 层 | 资产 | 十年后的样子 |
|---|---|---|
| 土壤 | danqing 引擎 + 兄弟 crates | 十年打磨的原生工具框架，单人开发者的真护城河 |
| 农夫 | 选型心法 + 全部 intent/调研/校准档案 | 校准过的判断力——几十份带日期的证据库，最稀缺的一层 |
| 渠道 | 分发足迹（论坛声望 / SEO / GitHub 星 / 落地页） | 复利最慢但只涨不跌 |
| 果树 | 活到那时的产品们 | 未知，也不重要——前三层保证果园永远能再种 |

诚实的区间：**地板 = Ditto**（十年爱好、零收入，但引擎和判断力真实增值，职业对冲成立）；**中位 = 几件产品各自零星结果**，农场成为工资之外的第二引擎（不必替代工资）；**天花板 = Obsidian**（3 个工程师五年 $3.5 亿——彩票，不是计划）。杠铃策略的含义：按中位规划，按地板兜底，给天花板留着门。

## livestock：鸡、羊、奶牛

livestock 的真正功能 = **树结果之前的现金流和士气**。映射：

| 动物 | 对应物 | 收获节奏 | 维护成本 | 什么时候养 |
|---|---|---|---|---|
| **鸡（蛋）** | 内容与分发足迹：发稿、踩坑记、使用故事 | 高频小额 | 极低——鸡吃剩饭 | **现在**，10-08 的分发准备就是鸡窝 |
| **羊（毛）** | 开源声誉：encoding/logfile 上 crates.io、框架公开 | 周期性剪毛 | 中 | 第 1–2 年 |
| **奶牛（奶）** | 订阅/服务/运营型收入 | 每天挤奶 | **高——每天要喂** | **现在不许养** |

三条注：

1. **鸡已经在下蛋了，只是没人捡**。各仓 CLAUDE.md 里的踩坑记、9312→34ms 的对照实验、PERFORMANCE_REPORT、「我在 2GB 日志里抓到线上 bug」——全是下好的蛋，分发准备的本质是**捡蛋**。
2. **奶牛是唯一能杀死农场的动物**。每天挤奶 = 服务器账单 + 客服 + 日常运营，会打破农场不死性的根基（Ditto 地板：零成本结构）和杠铃（工资养农场，不是农场养人）。Obsidian 养得起奶牛，因为那是它的全职、有 7-10 个人；买断制 + 离线 key 的设计，本质就是**自觉地不养牛**。第 3-5 年若某棵树结果到忙不过来再议——到那时是树养你，不是你养奶牛。
3. **pomodoro = 第一只还没下蛋的鸡**——蹲在商店里零成本被动待着，¥18 add-on 检验「商店渠道能不能转化陌生人」。不下蛋不致命，每个蛋都是渠道读数。
