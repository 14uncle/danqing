## 灵魂 (2026-09-03 用户确认「大体对」)

> 本节是主题层定义 (产品要表达什么); 推理链钉子 4 是形态层定义 (载体怎么活), 两层不是一回事。

**一句话: 你转身之后, 有东西替你活着。**

1. **主题: 注意力不是世界存在的前提。** 电脑上所有软件都为你的在场服务 (点击才响应, 打开才存在); 息壤是唯一只在你缺席时活的东西。零索取的极致不是「不打扰」, 是「不需要」—— 这个世界不需要被你需要。
2. **三个文化原型 (用户读得懂的通道):**
   - Toy Story 时刻: 你离开房间, 玩具活过来
   - 息壤本意: 不待耕作、自生自长的土 —— 名字就是主题
   - 「刚才下雨了」: 你没看见雨, 但地是湿的 —— 产品时刻不是看雨, 是看见湿地面; 留痕 = 「生命曾在场而你不在场」的证据, 即灵魂的技术形态
3. **对行业的表达: 它不争。** 注意力经济里每个 App 都在求 (通知/红点/打卡/连胜); 息壤回来即隐去、无推送无钩子, 宣言「软件可以不为抢占注意力而活」。农场生态位: pomodoro/clipboard 服务工作, 息壤是第一个不服务工作的产品 —— 只住在工作的缝隙里。「你忙你的, 它长它的」= 两个各自生长的生命, 偶尔撞见。
4. **边界**: 不是陪伴 (你在时它恰恰不在) / 不是美学策展 (拾光的岗位) / 不是效率 (拒绝钩子) / 不是游戏 (拒绝玩法)。
5. **灵魂 → 可检验的设计约束** (spec 评审按此验收):
   - idle 触发才是灵魂时刻, 热键是实用妥协 (夺舍 Win+L)
   - 回来即隐去的干脆 = 礼貌
   - 演化发生在你不在时 —— 你撞见的永远是「刚过完的」, 不是「正演给你看的」
   - 免费世界必须完整 —— 礼物不能缺角

## 推理链 (2026-09-03 interview 五颗钉子)

### 1. 小窗形态的三死因 (09-01 复核的具体内容, 用户原话)

付费点复核未过的实质不是「收费方式没设计好」, 是载体死结:

1. **遮挡工作区, 必定被关掉** —— 常驻小窗与工作区零和博弈
2. **小窗 < 全屏** —— 引擎护城河 (shader 场景视觉冲击力) 在小窗形态发挥不出来, 自断一臂
3. **无锚点零召回** —— 「零索取」灵魂反过来是零召回手段: 你不看它也在过 = 关了也没损失 = 永远关掉; pomodoro 有环境音还有番茄钟立在那里, 小窗什么也没有

结论: **pomodoro 已经是一个更好的「桌景」** —— 「召之即来」的沉浸打败「常驻碍事」的沉浸。

### 2. 载体与主题拆分

死的是「桌面常驻小窗」载体 + 「变现」岗位; 主题「有个世界在过日子」活着 (用户确认)。问题从「怎么收费」变为「主题换什么载体活」。

### 3. 载体海选 (处决名单)

| 候选 | 死因 |
|------|------|
| 锁屏界面 | Windows 不允许应用替换锁屏, 技术上不存在 |
| 桌面层动态壁纸 (图标下层) | 撞 WE 锋芒; 工作时被窗口盖住, 全屏冲击力是理论的 |
| 边缘条 (Rusty's 式屏底条) | 比小窗更小; Rusty's 活靠放置玩法钩子, 正是拒绝的东西 |
| 托盘微缩世界 | 同上, 更小 |
| 网页/新标签页/手机 | danqing 是原生引擎, 等于重写, 单人不可维护 |
| A: 并入 pomodoro 休息时段 | 过三死因但落选 —— 用户裁决「感动 > 划算」, B 的诗意胜出 |
| **B: 待机世界** | **选定** —— 过全部三死因: 离开故无遮挡 / 全屏冲击力 / 锚点 = 「我不在时世界过了什么」 |

### 4. B 的灵魂定义 (用户原话提炼)

1. 不锁屏离开片刻 (上厕所/去同事工位讨论), 回来发现桌面出现了一个全新的世界 —— **惊喜**; 对标「每天开机出现新壁纸」的吸引力
2. **热键召唤 = 替换锁屏** —— 夺舍 Win+L 习惯, 无需教育用户; idle 自动 + 热键手动双触发, 化解「触发窗口窄」风险
3. 对比静态桌面背景更立体: 底图 + 环境音 + 动效 + **跟着物理世界变换** (时辰/季节)

### 5. 定价: 免费 + 付费

- **免费 = 完整体验的一个世界**: 双触发/环境音/动效/时辰跟随全给足; 免费版必须是成品不是阉割品, 否则「回来的惊喜」变「弹出的广告」, 灵魂当场死亡
- **付费 = 买断世界包**: 收「想被更多世界惊喜」的钱; 原推演 DLC 结构原样复活, 场景生产线仍是内容工厂; 价格锚沿用 08-29 预钉 (单场景 ¥9.9 / 季节合集 3 场景 ¥22), 终钉留 spec
- **渠道 = 微软商店首发**: Partner Center/IAP 基建 (license.rs/add-on/买断制) 09-02 刚跑通, 复用边际成本≈填表; GitHub 照旧开源 + Release 挂免费版 (照 pomodoro 09-03「开源+免费+freemium」政策骨架); **Steam 不首发**, 与 pomodoro 的 Steam 另行合并评估
- **否决订阅制** (08-29 原推演否决理由继承 + 新增):
  - 品类心智买断 (WE/Spirit City/Rusty's/Tiny Pasture 全买断, 品类无订阅先例)
  - 单人内容负债: 订阅卖「持续服务的承诺」, 买断卖「这次的内容」, 单人开发不能卖承诺
  - **订阅 = 常驻索取, 与零索取灵魂直接冲突**: 惊喜是礼物, 租金是债务
  - 持续收入由季节合集买断承接; 「订阅=更高级变现」念头回来时按本条预防 (同 pomodoro 09-03 复盘条款)

### 拾光参照系 (2026-09-03, 造物主实测)

拾光壁纸 (造物主在用的付费壁纸应用) 付费点 = 每天一张好壁纸 + 图源很多, 且长期留存成立 (「拾光还在」):

- 证明: 低强度陪伴型产品可长期留存, 机制 = **持续供给的新奇** (策展品味 × 内容广度)
- 产能差异: 拾光的每日新靠聚合现成图源; 息壤的世界是场景生产线手作, 「每日新世界」不可能
- 等价物: 息壤的「每日新」发生在世界**之内** (时辰/季节/缺席留痕), 不在世界之间 —— 开放项 1 的验收形状: **单个世界的变化密度必须撑得起每日回访**
- 世界包 = 中周期新鲜感引擎 (月度/季度级), 管留存第二档不只是收入
- 一句话差异化: 拾光给你看一张图, 息壤替你过一段日子 —— 它记得你不在的时候

## 开放项 → 2026-09-05 spec 重启 interview 全部钉死 (用户显式 yes)

1. **「过日子」最小定义 = 三层全要, MVP 不砍离线补算**:
   - ① 状态真演化: 世界有内部状态随真实时间流动 (云走/雨来雨停/花开), 不是循环动图
   - ② 留痕可归因 —— 灵魂时刻: 回来撞见「刚过完的」证据 (湿地/落花/熄灭的篝火), 能读出「这是我不在的那 N 分钟里发生的」; 「刚才下雨了」原型即灵魂的技术形态
   - ③ 跨会话接续: 退出存状态+时间戳, 下次启动按真实经过时间补算演化; 关机睡觉世界照过 (Toy Story 幻想的完整版)
2. **idle 触发六条**:
   - 阈值: 默认 5 分钟 (GetLastInputInfo 会话级无输入), 设置给 3/5/10/15 四档; 过短会在「人还在读屏发呆」时夺屏, 违背「你在时它恰恰不在」
   - 抑制: 全屏视频/游戏/演示不触发 —— 查 `SHQueryUserNotificationState` (演示模式/D3D 全屏即抑制), 不自造检测; 会议投屏天然被覆盖
   - 多显示器: 全部屏幕一起接管, 世界延展到每块屏 (逐屏独立渲染); 只接管主屏 = 副屏亮着桌面, 沉浸当场穿帮
   - 回来即隐: 按键/鼠标点击即退, 淡出 <300ms (干脆=礼貌); 鼠标移动需位移 >50px 才算回来 (防桌震/猫误隐); 绝不学锁屏要密码 (那是索取)
   - 电源: 不阻止系统息屏/睡眠 (**一票否决项**, 阻止睡眠 = 头号索取行为); 息屏则世界挂起; 电池供电降帧 ~15fps, 插电全量
   - 热键: 全局可配置, 按一下立即召唤; 「夺舍 Win+L」是心智对标 (技术上碰不了 Win+L 本身), 默认组合键留 spec 试占用后钉
3. **编码时机**: spec 2026-09-05 即日开写 (五阶段逐段放行, spec 完不自动编码); build 排 pomodoro 商店闭环 (认证→发布→add-on 提报) 之后; 同日 clipboard 终止开发 (见农场 CLAUDE.md), 原「clipboard 节奏不变」约束消失, Xirang 编码队列实前提一位

**首个世界 (2026-09-05 钉)**: **雨天场景改造** —— 「刚才下雨了」是灵魂三原型中唯一自带技术形态 (留痕) 的, 来雨→雨停→湿地渐干天然就是演化+留痕的教科书表达, 雨声环境音是品类验证过的最受欢迎氛围; 次选 = 带晨昏时辰的场景 (时辰跟随展示面最大)。
