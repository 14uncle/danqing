## 深调研材料

### D4 · log 家族会材料（已完成 2026-09-25）

**功能面对照**（卡A 能力 × danqing-log 现状）：6 点里 **1 已覆盖**（外来编码可靠——encoding 直接复用）/ **4 相邻可扩**（大 CSV 打开——缺 RFC4180 行步进，正是「不丢行」卖点的技术面；列对齐——表格 UI 可复用但解析层 JSON 专用；只读安全——mmap 只读✅；dump 清洗——export CSV 写出有、读取清洗无）/ **1 log 定位外**（Excel 静默丢行叙事）。「引擎面重合高，产品叙事面重合低」。

**复用率**：引擎 ~70–80%（logfile 头部已预留「未来消费大数据文件的产品」；唯一硬缺口 = CSV 记录语义，约一个 csv.rs 模块，对标 jsonl.rs 规模）；产品层 ~30–40%（level 直方图/字段语法/工作台对 CSV 无映射）。

**三形态利弊**：
| 判据 | A. log 扩展 | B. 姊妹产品 | C. 独立第八件 |
|---|---|---|---|
| 品牌叙事 | ✗ 日志卖点被稀释，CSV 用户见日志 UI 困惑 | ✓ 各自干净，可讲同引擎家族 | ✓ 干净但复用叙事不可见 |
| 商店搜索词 | ✗ 7 关键词挤掉日志词两头不靠 | ✓ 双 listing 各 7 词+交叉引流 | 双货架但冷启动重来 |
| 付费层定价 | 两难（查看刚需收费易招骂；免费无新付费点） | ✓ 继承 $29/$59 锚 + licensing 轨 | 无锚需重做定价调研 |
| 开发带宽 | ✗ 打断 A–F 验收 21 项 + 付费层 + 前提③ | 半（引擎可排后，但新仓+新验收面） | ✗ 最重 |
| 组合纪律 | ✓ | ⚠️ 灰（事实双活跃） | ✗ 违反 |

**边界红线**：只读「查看器」不滑向 CSV 编辑（表格手术刀已毙，供给双热）；log「不做编辑」边界可共守；MS Store 名称发布后不可改。命名：LogLens 前缀族名=借信任也借稀释。
**粗算素材**：topic:csv-viewer **72 仓** vs log-viewer **379 仓**（csv 侧桌面 GUI 稀薄）；CSV 人群含 log 够不着的**非开发业务岗**（Excel 丢行受害者）；⚠️ **若在 10-18/10-21 校准钟响前加 CSV，校准数据被污染**（分不清下载来自哪个词）。
**三个裁决入口问题**：① 卡A 目标是「补 log 的 CSV 读入」还是「Excel 丢行人群独立产品」？② log 主线（验收→付费层→前提③→校准钟）允不允许再压模块？③ 若走 B：姊妹是否一 key 双产品？

### D1 · 多显示器深调研（已完成 2026-09-25）— 建议：**继续（需求过关）→ 转向窄楔子，不开全枪**

**竞品扒料要点**：
- DisplayFusion **活着但在漏**（v12.1.1 2026-07 + Beta 2026-09、论坛月产 ~40 帖、中国经销在营）：论坛缺口三大块——触发器缺显示器匹配维度（官方「加进 feature list」2026-09-22）/ 显示器身份与 profile 分组 / Window Position Profile 换桌失灵（「一天换桌 2-4 次…none of them end up on the correct screen」）/ 跨屏 DPI 尺寸记忆
- 免费侧：PowerToys **#58（503 reactions）用户原话点名要买 DisplayFusion MonitorSplitting = 付费逃逸铁证**；#2694/#4/#279 仍 open；**GrabAndMove 2026-04 动工 = 微软正在吃窗口管理**；GlazeWM/komorebi 12-15k★ 封死 tiling 极客侧；DisplayMagician 751★ 20 个月没发版
- **Win11 内化现状**：插拔坞「记住窗口位置」**已原生**（官方文档 2026-09-25）= 失效标志**部分触发**；未内化：per-monitor taskbar 选择 / 触发器 / 显示器 profile / Alt+Tab 按屏

**需求验证补强**：购买动机对位——t/66004 主题=多显示器 Alt+Tab（「有多个屏幕…Alt+TAB 会显示所有屏幕上的所有窗口」），与 DF Pro「Alt+Tab Handler」精确对位（至少一笔买的是跨屏窗口管理）；PowerToys #58 付费逃逸原话；DIY 潮未停（**taskbar-per-monitor 2026-09-07「Paid apps like DisplayFusion (~$38)…same thing in ~190 lines of C#」** = 窄楔子可行性+免费重做风险双证）；**人群画像具体：多屏换桌办公党/扩展坞插拔党/多窗口分屏党——不是 tiling 极客**（避开 tile 坟）；中文市场 displayfusion.cn 经销在营。

**定价**：DF Pro Standard **¥230/机** / Personal ¥332 / Steam **$39.99 买断**；建议农场位 **¥49–99 买断（$9.99–19.99）**——新人进不去 DF 同价（100+ 功能打不过），农场 log $29 / pomodoro ¥18 中间位合理；可套 freemium。

**粗算素材**：MS Store 货架极薄（"multi monitor" 3 款、window manager 0 结果——**品类用户习惯站外装**，与 DF 不进商店一致）；GitHub 侧 tiling 被 12-15k★ 封死；转化参照 appinn CTR≈5%、log 6 天 32 下载/6★。

**失效标志复核**：Win11 内化**部分触发且在缩窄**（中距：若 PowerToys 两年内收编 profiles+triggers，缝塌）；DF 停售远未触发。新增失效标志候选：① Win11/PowerToys 支持 per-monitor taskbar 开关+原生 window position profiles；② DF 免费化/下放 triggers。

**风险**：全品类硬刚=tile 死法（DF 功能面 100+ + 免费平铺双杀）；窄楔子可被 190 行 C# 重做；MS Store 与品类错位；人群叙事必须避开 tiling。

**建议**：**继续（需求过关）→ 转向窄楔子**。楔子：**A 插拔坞/换桌「窗口位置配置文件」**（Win11 原生记忆的上位替代：预设/多地点/应用规则）+ **B 按屏任务栏选择**（190 行 C# 实证可行，DF 卖 $38）；C 轻量触发器最热但最可能被 PowerToys 收编，单独立项风险高。**组合 A+B**（同为多屏办公人群）。若终裁判「窄楔子撑不起产品」→ 放弃归档。

### D2 · iPhone 备份深调研（已完成 2026-09-25）— 建议：**转向**（降 T2 观察 + 收窄切口 + 开枪前置两证）

**需求验证**：DIY 波比立案时**宽一倍**（≈12 真实自建仓 2022-12→2026-09，英/西语多语种，2026-04→09 半年 ≥7 起新仓 = 活且陡）；**但用户聚合≈0**（全部 0-2★、零 issue）——证明「个人在凑合」不证明「用户聚到产品上」。**付费短板**：无一条「我买了 iMazing」自白（渠道墙挖不到）→ 付费证据=间接（商业在售+销量自述）。

**定价**：建议 **¥29–49 买断（$9.99–14.99）**——iMazing ¥198 十倍差是楔子也是天花板信号（窄功能不支撑高价）；MS Store 同类全免费。

**载体路径（执行层）**：**`idevice` crate（jkcoxson 纯 Rust，515★，AFC feature，已被生产使用）——Rust 单文件 GUI 路径已存在**；风险=0.2.0 前每点版本 breaking。工时：照片窄角（AFC 拉 DCIM+diff+HEIC+月目录+校验）≈ 小；全设备 backup2=深水砍掉。**协议追新是持续税**（iOS 26.x 破坏史连续，OrchardBridge 2026-09-19 仍在追 iOS 27.x）。

**失效标志复核**：MS Photos 修好（未兑现）/ Apple 官方端转好（**分裂**：Devices 差但 iCloud 好——「传输」大面已被 iCloud/PhotoSync 服务，**唯一守得住的缝=USB 直连/无云/可验证**）/ DIY 停更（未兑现，波在加速）/ pymobiledevice3 归档（未兑现）。

**建议：转向**——① 凑合证据真且温度陡，判死不符合新指南；② 付费短板（零自白）+ ③ 缝窄到更像功能不像产品 + ④ DIY 零用户聚合 + ⑤ 协议追新持续税。**落点：降 T2 观察卡，切口钉死「USB 直连 · 无云 · 可验证差异备份 · 单文件」；开枪前置两证：A. 一条真金白银的竞品购买自白（渠道恢复后挖）；B. 2026-Q4 实机复现 MS Photos 导入失败。** 若用户仍要开枪：v1 只做照片窄角、¥29–39、idevice crate 钉版本、iOS 大版本发布周设兼容追修日历。

**取证局限**：reddit/appinn/archive 被墙；iMazing 美元价、PhotoSync IAP 档位、中文求助浏览量=未验证。

### D3 · 微信归档深调研（已完成 2026-09-25）— 建议：**放弃**（合规死刑，不死于需求）

**合规评估（五项，结论：不可为）**：
1. **ToS 明文**（腾讯微信软件许可及服务协议，2026-09-25 取证）：**8.2.1.6** 禁经第三方工具对数据自动化访问，且禁**「制作、发布、传播」**此类工具——产品化分发本身即违约；8.2.1.2 反编译 / 8.2.1.7 绕过安全措施 / **8.3.7** 制作传播违禁工具（无论商业）/ 2.3.1 仅非商业单机 / **7.2.4.2 用户可自行备份**（唯一合规钩子）/ 8.5.1 违约封号。
2. **法律边界**：具体判例**未验证**（检索通道全被阻断，不编造）；可核实风险面——著作权（归档灰色可辩护、再分发/商用 RAG 侵权）+ 刑法 285 条风险面（MITM+根证书+拦截 key/pass_ticket 具「技术手段获取」特征）。「不绕过登录」挡不住合同违约——批量工具经用户凭证自动化访问仍被 8.2.1.6 覆盖。
3. **工具存亡史**：wechat-article-exporter **12.9k★ 2026-07-30 死**——死因=「上游核心接口被微信关闭」（**平台关接口灭品类，非诉讼**）；频控实证（`200013:freq control`）；qiye45 作者「有风险，但还没看到封号案例」；灰产在场（「让我挣了 3k，只跑了几个月」2026-08-31；明文禁售条款=倒卖生态）。
4. **路径盘点**：a 官方能力无批量导出（缺口真实）/ b 手动整理合规但砍半需求 / c 缓存解析仍落深水 / d 单篇公开 URL 存档**合规**但=砍掉批量核心+clipper 红海。**技术路径真相**：wxdown-service = mitmproxy+装根证书解密微信 HTTPS+拦截凭证（25 分钟有效）= **「协议逆向深水」正面命中农场红线**；qiye45/exporter 同族。
5. **结论：不可为（批量归档产品本体）**——红线命中 + ToS 分发禁令（商业化本身=违规）+ 平台已展示关接口灭品类能力 + 判例未验证≠安全。灰色地带写明：个人自用灰工具有低风险实证；**收钱做批量导出=踩分发禁令**。

**需求侧（活着，但救不了它）**：#200 停更公告 61 评论三画像（抢救行业资料/论文归档/长辈十年号）；2026 年内 62 个同主题新仓自建潮；**RAG/知识库新叙事已起**（Obsidian/Dify/RAG 切片、MCP/Skill）——人群从收藏党扩到 AI 语料党。**三条失效标志全未触发 = 需求活着**。

**定价**：Mp2RSS SaaS 49/99/399 元/月（订阅位，与农场买断锚不同轨）；xzfans 愿付区间未验证。

**建议：放弃**。死线 = 农场红线「不做协议逆向深水」+ ToS 分发禁令型合规死刑。**方法论沉淀：「付费实锤 ≠ 可做；分发禁令型 ToS 是产品死刑不是用户风险」——本卡是「需求成立但合规死刑」的标准案例，入案卷。** 唯一活口（路径 d 单篇存档器）= 另一产品（clipper 红海），需重走选型，不算本卡转向。

## 红线适用边界（红队 #18 要求的对表条款）

- **红线内（不碰）**：第三方服务的凭证拦截/HTTPS 解密/自动化访问（微信卡死因）；内核驱动；协议逆向自研。
- **红线外（可为）**：自有设备 USB + 用户授权 + **现成开源协议栈代劳**（idevice/pymobiledevice3）——逆向由社区库承担，非农场自研。
- **残余责任**：外包逆向 ≠ 深水消失，协议追修=持续税——**设阈值**：若 iOS 大版本追修连续两季 > 5 人日/季，视为深水回归，观察卡作废。
- 多显示器窗口钩子=**文档化 Win32 API**（SetWinEventHook 等），非逆向（tile 时代「与 app 开发者打游击」的结构负债另册记档）。
