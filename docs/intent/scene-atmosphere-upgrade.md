# 场景氛围整体升级 —— 统一血统下的四场对症手术

- @author 十四叔
- @date 2026/08/03
- 状态: 已确认 (interview-me 流程, 2026-08-03 用户显式 yes)

## 一句话

星夜六场景的沉浸氛围整体升级到"让人有掏钱冲动"的水位;**统一 AI/程序化血统一寸不动**,逐场景对症下药,海/雨封存为验收基准。

## 背景:为什么有这个意图

- 起点是用户的一个直觉判断:"静态背景图是 AI 生成的,沉浸美学差点意思,达不到让人掏钱的冲动",并提议从开源图库下载图片换血。
- interview-me 逐场景诊断后,真因浮现:**差的是"图+动效整体氛围",不是 bitmap 来源**;且六个场景是五种不同的病,不存在一把钥匙。
- 海/雨两场景"没调出毛病"——证明现有管线摸得到付费线,问题在执行不齐,不在路线。

## 否决的方案:开源图库换血

"场景背景图从开源库(Unsplash/Pexels 等)下载"——作为全量换血被否决:

| 维度 | 否决理由 |
|------|---------|
| 病因错配 | 缺口在氛围系统(图+动效+声音+时间演化),换 bitmap 治错了层级 |
| 动效自由度 | 真实照片上大幅度 UV 位移/视差立刻露馅,只能做微动效——氛围不够时收缩动效,方向是反的 |
| 血统割裂 | 六场景混入摄影资产,切换时"换了一个产品";用户显式拒绝"银河用真实天文摄影做底"的例外 |
| 十年叙事 | "每一个像素都是自己的管线产的"是著作型旗舰的品牌资产,摄影换血会打断它 |
| 授权灰区 | Unsplash 类条款对"付费场景"存在"未经实质性修改不得售卖"灰区,且有"付钱买免费图"的感知风险 |

注:星空场景曾单独评估 NASA/ESA 真实天文摄影例外(授权干净、暗底与程序化动效兼容),用户**显式拒绝**,理由为坚持统一血统。此例外永久关闭。

## 已确认的意图 (restate, 2026-08-03 用户显式 yes)

- **Outcome**: 六场景沉浸氛围整体升级到"让人有掏钱冲动"的水位;统一 AI/程序化血统不变
- **User**: 星夜的(潜在)付费用户;终审眼睛 = 十四叔本人
- **Why now**: AI 生图天花板已摸到;里程碑 1 刚把场景收敛为 6 个(Task I),正是质量收口窗口;付费边界 spec 已定(Task H),场景质量是付费转化的前置条件
- **Success**: 每个改过的场景与封存的**海/雨并排盲切,至少不输**——这是钉死的方法学。留一个决定项:是否拉 3~5 个目标用户看第一反应(防自评阈值漂移),执行前再定
- **Constraint**: 不引入任何外部图库/照片/视频资产;森林的动效与声音一寸不动;海/雨封存不碰
- **Out of scope**: 路线变更(已关闭)、新增场景、剪贴板 POC、付费边界 spec 改动
