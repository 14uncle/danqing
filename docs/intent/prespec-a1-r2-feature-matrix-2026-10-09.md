## 0. 一句话结论

**「剪贴板进 → 本地转换 → inline-CSS HTML 出 → 用户自己粘」这个座位九家全空**：Web 双巨头（秀米/135/壹伴/96）是「在我这写在我这排」的模板库闭环；开源三件（doocs/md、mdnice、wenyan-pc）是 Markdown **编辑器**（要先粘进编辑区再点复制）；skill 双新贵（md2wechat/gzh-design）是 AI-agent 附属品（要先写完 MD 再叫 agent）。**输入侧剪贴板/CF_HTML 双路 = 独有；输出侧 docx = 独有（26 份头部 README 零命中，本轮 gzh 只把 docx 当输入）**。我们独缺的最痛三条：直推草稿箱、长图导出、图床/图片上传。价格温度计新读数：**¥199 永久买断标价仍在（md2wechat，2026-10-09 当日抓取）** vs 灰市代充 ¥4.8/15 天——买断标价与灰市地板并存，¥25 记账口径落在两者之间但贴近灰市心理价位。

## 7. 对 spec 的三条最硬输入

1. **输入侧是我们的主场**：剪贴板双路（MD+CF_HTML）九家全空，且直接命中「AI 对话复制丢格式」痛点——spec 的 F 条目应把「CF_HTML 零损失路径」写成 P0 验收项。
2. **输出侧守剪贴板、不做草稿箱**：md2wechat/wenyan 已做草稿箱，但我们 v1 的「用户自己粘」是合规选择而非能力缺失；spec 里要写清边界，避免被问「为什么不做直推」时答不上。
3. **价格带警示**：免费地板（doocs 13412★）+ 灰市 ¥4.8/15 天 + ¥199 标价并存；¥25 记账口径不离谱但转化论证仍缺——首单外检是唯一裁判，spec 锁定会上呈「免费层先行 vs 买断」照 prespec-a1 待裁项。
