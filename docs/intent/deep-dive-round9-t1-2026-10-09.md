## 卡A 案底(抄自 round9 卷)

- **需求**:跨多文件夹收文件(邮件附件/U盘/交付物)缺「中转暂存架」——从各处丢上架、一次拖出到目的地,替代多开资源管理器互拖。
- **凑合行为(带日期)**:Holdem README(2024-09,152★)「juggling Explorer windows, losing your drag mid-way, or dropping things on the Desktop "for now"」;Bucket README(2026-06)「opened five File Explorer windows… We've all accepted this workflow. We shouldn't have to.」;土法=丢桌面「暂时放着」。
- **付费证据(形态侧对位成立)**:Dropshelf(商店 9MZPC6P14L7N,免费层+Pro)issue 区买家自白 ×5:2025-04-29 / 2025-09-23 / 2026-01-12 / 2026-05-17 / 2026-05-29(「1.0.10.0 pro」自报版本号)。Mac Yoink/Dropover 付费生态 = 第二手转述(Bucket/Holdem README 原文)。
- **手搓簇 ≥6 仓**:holdem(2024-09)/ Bucket(2026-06)/ ghost-drop(2026-07)/ shelf-Mac(2026-02)/ omarchy-ledge(2026-08)/ PyDrop(2021)。
- **推断链**:现象(同形态多仓独立手搓+双侧付费)→ 本质(Explorer 是「浏览/移动」模型,缺「暂存/合流」环节)→ 什么在变(文件来源更碎、发件仍日常、vibe-code 让手搓成本暴降)→ 方向(便携 GUI 暂存架,免费层+买断 Pro)。**断环(补证目标)**:Mac 第一方销售数据;人群分层;「发出去」动作的具体链路(邮件/聊天/U盘各占多少)。
- **失效标志(卡上已有)**:① Dropshelf 停止 Pro 变现/年活<1k;② 2026-10 后 6 个月无新暂存架工具且 holdem/Bucket 停更;③ Windows 本体/PowerToys 上线拖拽暂存区(系统吸收兑现);④ DropIt/Direct Folders 免费在位者查实覆盖同形态且活跃。
- **早筛透镜(R2 初判)**:系统吸收远 / AI 未接走 / 免费在位者薄(Dropshelf 免费层有 wait timer)/ 付费分布非僵尸——**四行全部要 D1-D3 复核**。

### Q4 · 引擎适配 + 一页粗算(agent 自查 + 回卷后合成)

**引擎盘点(2026-10-09 本会话自查 danqing/src)**:
- 置顶悬浮窗:**有**(`WindowConfig.topmost` + `WindowEventSender::set_topmost`,桌景肌肉)
