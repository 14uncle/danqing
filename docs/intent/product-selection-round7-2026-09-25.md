## 任务定义（保护项）

- **权威判据只有一句**：「谁还在为这件事凑合？证据呢？」（新指南第一条）；推断/培养路径走第二条（现象起点 + 推理链书面 + 失效标志前置）。
- **本轮双轨**：① **旧案复审**——之前被判死的候选/近失格/死池品类，凡死因属于**已废条款**（免费例外 /「X 但更好」死刑 / 缝隙三判据 / 准入三问 / 双半独立条目 / 许可条款）的，一律重审；② **新现象扫描**——带「谁还在凑合」去行为源里捞现象（line 1 凑合行为 + line 2 现象推断）。
- **维持原判的三类**（不重审，只注明）：死因是**证据性**的（实证没人凑合/需求已被满足）、**实现约束**（内核/逆向深水）、**质检边界**（读不懂的深专业域）。
- **坟头纪律不破**：clipboard / xirang / disk / tile 的**产品**坟不动、不主动重启；本轮只复审其背后的**需求**（剪贴板历史/待机世界/磁盘分析/自动平铺）。任何需求翻案，重启对应产品是**用户专属按钮**。
- **成功线**：≥1 条立案候选（新候选卡齐全，见下）→ 呈用户裁决。零立案同样呈裁决（流程不自喊停）。
- **Out of scope**：不写产品代码；分发不加注（09-28 回读照台账）。

## 候选卡格式（新指南下唯一格式）

1. **需求**一句话
2. **谁在凑合**：具体人群 + 凑合行为（绕道/土法/掏钱/给免费工具擦屁股），**带 URL + 日期**，言词抱怨不算
3. **证据强度**：来源数（≥3？）/ 行为证据类型 / **付费证据单列**（掏钱=最强；抢救免费工具只证明需求在）
4. **需求温度**：相关帖/issue 的**创建日期分布**（活 / 衰减（老票多新票无）/ 迁移中（增量人群被 AI/邻近管线接走））
5. **推断链**（line 2 适用）：现象 → 本质 → 什么在变 → 方向，哪环没证据哪环断
6. **失效标志**：出现什么证据 = 这条错了（写不出不立卡）
7. **载体一句话**：Windows 桌面单文件 GUI 可为性（执行层信息，不作选型否决）
8. **判定**：立案 / 毙 + 依据

## 旧案复审规则

死因 → 处置对照：
| 旧死因 | 新处置 |
|---|---|
| 免费例外封死（免费在位者睡不睡都封死） | **重审**——新测试不是「有没有免费工具」而是「还有没有人凑合」；免费工具好≠没人凑合，看 issue/求助里的行为残留 |
| 「X 但更好」死刑 | **重审**——楔子与凑合证据合法 |
| 缝隙三判据 / 准入三问 / 双半独立条目 / 许可条款 | **重审**——条款已废 |
| 需求衰减型（实证老票多新票无=没人凑合了） | 维持（这就是新法的「拿不出凑合」） |
| 实现约束（内核驱动/逆向深水） | 维持 |
| 质检边界（深专业域读不懂） | 维持 |
| 人群不存在（说不清「谁」） | 维持 |

## 扫描结果 · 压缩摄取

### B2 新现象·中文桌面域（已完成 2026-09-25）— **立案 ×3（含全场唯一付费实锤）**

**域总评**：凑合密度中高。「自荐潮的『起因是/嫌 X』就是凑合史」比求推荐更干；土法仪式（桌面上的重启 .bat、第二台手机备份微信）是最硬的言词替代。中文桌面「掏钱」密度显著低于「土法」密度——全场付费实锤仅 1 处。

**卡A · 微信公众号内容批量本地归档——立案（付费实锤最强）**
- 谁在凑合：xzfans「下载到 windows 本地硬盘作资料库…**付费下载了一批文章，省时省力！**」（2024-03-18 真实付费，meta.appinn.net/t/53786）；Aquamarine 用灰色导出助手+2026-06 仍折腾更新包（t/86420）；开发者 zyzlywq 连发 WeChatExport 九格式（2026-06-04）+ WeChatVideo 视频号批量（2026-06-22）= 两份凑合史自述
- 证据 ≥4；**付费=有（2024-03-18）**；温度活（2024-03→2026-06 两年跨度新帖）
- 失效：微信官方批量导出/收藏可检索 / 工具簇 12 个月零新帖 / 封杀后无人找替代
- ⚠️ **腾讯反爬/封号/合规阴影未量化**——深挖第一项必须是合规评估（涉协议逆向边缘）
- 判定：立案

**卡B · 应用启动器（Listary 代）——立案（行为最纯）**
- 谁在凑合：「崩了一两年，**我甚至创建了一个叫 `重启Listary.bat` 的东西放桌面上**」；「5.x 稳定但费眼，6.x 随机崩…必须强杀重开」；「Xiaoyao+Everything 组合顶」；开发者「**嫌 Listary 很久不更新**」自建 Lertaro（=给付费工具擦屁股）。同帖 387 回复/10923 浏（t/87727，2026-07-02 起）
- 证据 ≥4；付费无直接掏钱（「十年老粉」身份暗示不计）；温度**活且陡**（本轮最高互动簇）
- 失效：Listary 连续两版修稳恢复发版（查 release 带日期）/ Lertaro+Everything 吃掉缺口后土法帖 6 个月零新增
- 判定：立案——**与 A2 弱线索「启动器」合并，本卡为准**

**卡C · 屏幕内容识别→翻译/提取一键闭环——立案（带迁移警报）**
- 谁在凑合：「当前的解决办法就是截图然后丢谷歌翻译里」（t/65995 2025-02）；截图→分享→Google Lens 四步绕道；试遍 Umi-OCR/STranslate/Panda 都不满意 → ShareX+Quicker/AHK **工具链拼装**（t/78286 2025-12）；「截图发给 AI 聊天窗口」「扔给豆包」；PDF 指定位置 OCR 进 Excel 等 2024-11→2026-07 持续

- 失效：Win11/浏览器/输入法内置识屏翻译默认化且求助 6 个月零新增
- 判定：立案——**三卡中最可能被 AI 原生功能吞掉的一条，裁决段必须正视**

**现象清单（载荷不成卡）**：EXIF 批量整理土法（「一股脑拷贝到一个文件夹…几万个…电脑卡得动不了」2026-08-21，单源）；键鼠宏后台回放（糖果浏览器录播失灵，单源）；Excel/CSV 土法簇（UTF-8 CSV 双击乱码 32 帖 / 2-3GB xls 想买 LLM key 做 diff / VBA 顺序粘贴）；PDF 中文增强（SumatraPDF Plus 275 帖=位置被占）；微信本地膨胀 70G+双开土法；开机自启手动关界面（WinTray 起因自述）；跨窗口搬运仪式（sspai 三连 2026-09-24）；Markdown 预览来回哆嗦（49 帖）；云盘替代长跑（服务型）。
**方法论（载荷）**：① 自荐潮「起因是/嫌 X」=凑合史，比求推荐干；② 求推荐必须挖「我现在用什么」；③ 土法仪式是最硬的言词替代；④ 中文 Discourse 用分类流+定点 `/t/{id}.json`，短词 search.json 不可靠；⑤ 付费证据只挖到 1 处——中文桌面掏钱密度 << 土法密度。
