## 候选卡格式(与 round8 同款,第 3 项主序)

1. **需求**一句话
2. **谁在凑合**:具体人群 + 凑合行为(绕道 / 土法仪式 / 在错工具里硬扛 / 为邻近品掏钱 / 给免费工具擦屁股),**带 URL + 日期**,言词抱怨不算
3. **证据强度**:来源数(≥3?)/ 行为证据类型 / **付费证据单列**(买断自白 > 捐赠订阅自述 > 标价不算;**形态侧付费对位**:这钱是不是为「拟做形态」掏的)/ 需求温度日期分布
4. **需求温度**:活 / 衰减(老票多新票无)/ 迁移中(增量被 AI / 邻近管线接走)
5. **推断链**(心法二适用):现象 → 本质 → 什么在变 → 方向,哪环没证据哪环断
6. **失效标志**:出现什么证据 = 这条错了(写不出不立卡)
7. **载体一句话**:Windows 桌面单文件 GUI 可为性(执行层信息,不作选型否决)
8. **判定**:立案 / 毙 + 依据

## 判据

- **立案**:候选卡 8 项齐全且「谁在凑合」有 ≥3 来源行为证据 → 呈裁决。**付费 / 形态侧对位越硬,座次越高**(本轮座次主序)。
