## 一句话

功能平权追赶 Ditto 是死路 (它二十年积累); C 轮的赢面在它**结构性抄不走**的三根支柱上加深 —— 颜值、隐私、中文场景。

## 凭什么选 danqing-clipboard (对标 Ditto)

- **输局先认清**: Ditto 有群组/快捷贴槽/便携版/网络同步/数百选项。照它的清单打永远慢二十年, 且每追一条都在稀释「克制」。
- **赢面三支柱**:
  1. **颜值即理由** —— Ditto 是 MFC 对话框时代审美, 用户忍 UI 换功能; 自绘暖纸 + 玻璃浮层是稀缺品,「愿意截图」本身是传播机制。对审美敏感人群 (mac 迁移者/设计师/开发者颜值派), 这一条就足够成为选择理由。
  2. **隐私是姿态不是选项** —— Ditto 默认存一切; 我们把「剪贴板里有密码」当第一天的问题: 密码管理器排除内置 / 暂停 / 清空 / 本地 SQLite 零网络 / 数据格式为十年设计 (加密字段已预留)。加密落地后是 Ditto 讲不出来的故事, 敢印在封面上。
  3. **中文场景一等公民** —— IME 组合期处理 (占位让位/光标/TSF 坑都趟过)、中英文混排、文件路径省略保留文件名。Ditto 对 CJK 是「能用」, 我们是「讲究」。
- **打平项不追加投入**: 键盘流速度感 (唤起即输入/回车即贴/三秒闭环) 与 Ditto 打平, 守住即可。

## 候选落点 (按支柱归位)

- **顺手** (等 dogfooding, 不提前拍脑袋): 用户日常用一两周, 摩擦自己浮出来。预判候选: 数字键直贴 Top 9 / Shift+Enter 贴为纯文本 / 收藏 pin / 来源应用标识 / 容量与清理策略 UI。优先级让真实使用说话。
  - **数字键直贴 Top 9** (2026-08-17 确认): 唤起面板后按 1-9 直接贴对应条目并关闭, 三秒闭环缺此不可。是效率闭环的硬缺口, 优先级最高。
- **隐私第二件**: 排除名单 UI 化编辑 + 加密落地 (SPEC 数据格式已预留字段, 不用动格式)。
- **美学第三件**: 暗色主题 / 克制版动效微光 (沿袭 `docs/ideas/danqing-scene-immersion-pivot.md` 效率工具剂量)。
- **命名** (2026-08-17 用户提出又搁置): 「clipboard 太普通」—— 候选 拾遗/复见/拾贝 已呈, 用户当日定「先不改」。若日后重启: 发布前改成本最低 (仓库私有期), 涉及 仓库名 / crate 名 / exe 名 / %APPDATA% 数据目录 (需迁移或兼容) / README 与发布页。

## 明确不做

网络同步 / 插件系统 / 跨平台 —— 都违背零网络与克制, 做了反而模糊定位。
