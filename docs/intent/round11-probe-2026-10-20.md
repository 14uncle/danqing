# round11 探针计划（2026-10-20）

> 用户裁决：行为推断轮后，对「核验台 · PDF/UA」与「片段即单位」**两个都做探针**。
> 本卷只含探针材料与门槛；不写产品代码、不进 spec、不动当前队列。
> 探针目标：用最小成本拿到「陌生人是否愿意付钱」的读数，而不是验证功能。

## 一、总则

- **两条探针并行，7 天收口。**
- 每条探针 = 10 个目标用户访谈 + 1 个假门页面（100 UV）。
- 访谈由用户本人执行（15–20 分钟/人）；agent 负责材料、记录模板、读数汇总。
- 不承诺产品、不收款（预售只收意向，不实际扣款）。
- 通过线：访谈 ≥3 人明确愿意付 ≥ 目标价，或假门 100 UV 留邮箱 ≥2%。两条任一达标即进入 spec 评估；两条都不达标即判死。

## 二、探针 A · 核验台 · PDF/UA

### 目标用户

无障碍修复师、高校/政府文档岗、小型无障碍外包商。不是普通办公用户。

### 招募渠道

1. WebAIM 邮件列表（webaim.org/discussion）——行为推断路 C 已确认可直接读帖，可发问。
2. LinkedIn：Accessibility Specialist / PDF Remediation / Section 508 Coordinator 群组。
3. r/accessibility（Reddit；用户本人网络可达时）。
4. 高校 Disability Services / IT Accessibility 办公室邮件。
5. 国内：信息无障碍研究会、无障碍相关公众号/社群（若能触达）。

### 访谈脚本（15–20 分钟）

1. 你每月要修多少份 PDF？大概多少页？
2. 上一次修复，从头到尾用了哪些工具？花多久？
3. 时间主要花在哪：打标签、阅读顺序、表格、Alt 文本、还是校验？
4. 现在用 Acrobat、CommonLook、PDFix、axes4、Allyant，还是别的？年费/按页大概多少？
5. 自动打标签的结果，你敢直接用吗？为什么？
6. 你怎么校验——PAC、veraPDF、读屏实测，还是人工看？
7. 现在最烦的一步是什么？如果只能改一件事，你改哪件？
8. 如果有一个工具把「原文 / 标签树 / 差异清单」放同一屏，逐项确认，能省多少时间？
9. 这样的工具，你愿意一次性买断吗？多少钱算合理？什么情况下你会换掉现在的工具？
10. 我能给你看一个界面草图，听听你的第一反应吗？

### 假门页面

- 标题：**PDF/UA 修复台——原文、标签树、差异清单同屏，逐项确认**
- 副标题：离线、买断、Windows；自动初标之后，把复核变成一张清单。
- 三个卖点：① 原文与结构同屏，不用来回切；② 阅读顺序/表格/Alt 逐项确认，可回看出处；③ 导出 PAC/veraPDF 校验报告。
- CTA：**预约 15 分钟访谈**（mailto/表单）+ **留下邮箱，出内测版时通知我**。
- 声明：这是产品调研，不是正式销售；不收款。

### 通过线

- 访谈：≥3/10 明确愿意付 ≥¥399（或 ≥$99），且能说出当前年费/按页成本。
- 假门：100 UV 中 ≥2 留邮箱，或 ≥1 预约访谈。
- 反证：≥6/10 说「Acrobat/现有工具够用，不会换」→ 判死。

## 三、探针 B · 片段即单位

### 目标用户

10TB+ 原片的视频创作者：婚礼/活动剪辑师、纪录片剪辑、YouTube/B 站长视频创作者。**必须是 Windows 用户**（Mac 用户不计入通过线）。

### 招募渠道

1. r/editors、r/videography、r/VideoEditing（Reddit）。
2. V2EX 摄影/视频节点。
3. B 站/小红书/抖音创作者社群、剪辑师微信群。
4. 本地影视/婚礼摄影工作室。

### 访谈脚本（15–20 分钟）

1. 一个项目大概拍多少素材？存在哪（本地盘/阵列/NAS）？
2. 上次找一个月前的某个镜头，你是怎么找的？具体动作是什么？
3. 你用代理文件吗？生成一次要多久？
4. 现在用什么管理素材：文件夹、Eagle、BillFish、Pixcall、Premiere/Resolve 的媒体库？
5. 找素材最烦的是什么：命名、文件夹、记忆、换盘、还是软件卡？
6. 有没有因为找不到片段而重拍、放弃、或熬夜翻盘的经历？
7. 如果输入「孩子回头笑」「烟花升空」就能跳出那个片段，直接拖进时间线，对你值多少？
8. 一次性买断 ¥99/¥199/¥299，你愿意付哪档？什么情况下会换掉现在的工具？
9. 你主要用 Windows 还是 Mac？素材盘是什么格式？
10. 我能给你看一个界面草图，听听你的第一反应吗？

### 假门页面

- 标题：**30TB 素材，一句话找到那个镜头**
- 副标题：不改文件夹、不上传；本地索引，片段直接拖进时间线。
- 三个卖点：① 按内容/台词/画面找，不靠文件名；② 入库即生成代理与索引；③ 片段卡直接拖进 Premiere/Resolve。
- CTA：**预约 15 分钟访谈** + **¥99 预售意向（不扣款，仅登记）**。
- 声明：这是产品调研，不是正式销售；不收款。

### 通过线

- 访谈：≥3/10 是 Windows + 10TB+ 用户，且明确愿意预付 ¥99–299。
- 假门：100 UV 中 ≥2 留邮箱，或 ≥1 预售意向。
- 反证：≥6/10 说「文件夹/Everything/Eagle 够用，不会换」→ 判死。
