## 任务定义（保护项）

- **权威判据只有一句**：「谁还在为这件事凑合？证据呢？」（心法第一条）；推断路径走第二条（现象起点 + 推理链书面 + 失效标志前置）。
- **成功线**：≥1 条立案候选过闸呈裁决（候选身份 = **开工许可证**）；零立案照实呈 + 失败自检（流程不自喊停）。
- **本轮主攻轴 = round7 元发现落地**：需求侧证据容易挖，**形态侧付费原话（「为拟做形态掏过钱」）才是稀有物**——T1 三卡全灭于此。本轮换抓法：**从掏钱行为出发反向挖**，不再从抱怨正向扫完再找付费。
- **Out of scope**：不写产品代码；分发不加注（09-28 回读照台账）；不复审 round7 立案卡（新法产物，观察名单/挂钟在档，重挖=重复劳动）；坟头纪律不破（clipboard/xirang/disk/tile 产品坟不动）。

## 候选卡格式（与 round7 同款，第 3 项加权重）

1. **需求**一句话
2. **谁在凑合**：具体人群 + 凑合行为（绕道/土法/掏钱/给免费工具擦屁股），**带 URL + 日期**，言词抱怨不算
3. **证据强度**：来源数（≥3？）/ 行为证据类型 / **付费证据单列**（买断自白 > 捐赠订阅自述 > 标价不算；**形态侧付费对位**：这钱是不是为「拟做形态」掏的）/ 需求温度（帖/issue 创建日期分布）
4. **需求温度**：活 / 衰减（老票多新票无）/ 迁移中（增量被 AI/邻近管线接走）
5. **推断链**（心法二适用）：现象 → 本质 → 什么在变 → 方向，哪环没证据哪环断
6. **失效标志**：出现什么证据 = 这条错了（写不出不立卡）
7. **载体一句话**：Windows 桌面单文件 GUI 可为性（执行层信息，不作选型否决）
8. **判定**：立案 / 毙 + 依据

## 扫描结果 · 压缩摄取

### R2 英文消费/办公桌面域（已完成 2026-09-25）— **弱卡 ×2 + 压线 ×1**

**域总评**：可达性两极——SE API（superuser/softwarerecs）+ HN Algolia + 定点 gh api 有效；**Reddit 全线 000、ElevenForum/TenForum/AskWoody 全 403、WebSearch 空**（指定源四个灭两个半，实际域 = SE+HN+GitHub）。最大行为簇=「对抗 Microsoft 强推」（手搓 store.db SQLite / $UsnJrnl 法证 / reg load），但免费在位者极厚（WinUtil 63k★/Win11Debloat 57k★/ExplorerPatcher 34k★/ContextMenuManager 20k★）。**付费证据全轮零命中**——与元发现一致。可挖窄缝在「粘贴清洗」与「缓冲救回」，不在清理/卸载/菜单红海。

**卡A · 规则化粘贴清洗器（去格式但保超链接 + 清 CR/修编码）——弱卡**
- 凑合：LibreOffice「粘贴→清除格式」两步舞（SU 1932414，2025-12-13）；Win+V 粘贴文本丢链接文字（「This won't work for link texts」）且推荐者自认不确定 CopyQ 能不能干；「避免网页复制副作用」（1856113，2024-09）；去 CR（1902895，2025-05）；Phone Link 粘贴变标题（1925295，S:15）
- 证据 5 来源 ✓；**付费=零**；温度活（2024-09→2026-05 无断档）
- 推断链：粘贴转换被做成「全文本 or 全格式」二选一 × AI 输出成主复制源 → 规则化粘贴引擎（保链接/剥样式/清空白/修编码）。断环：付费买家画像无数据
- 失效：PureText/PowerToys/CopyQ/Ditto 任一文档明示「保留超链接的去格式粘贴」且 SE 半年无同类新题
- 判定：**弱卡**——下一步先去 CopyQ/Ditto/PureText issue 核实 keep hyperlinks 是否已提/已做
- ⚠️ 坟头核对：只做「粘贴时转换」，不碰剪贴板历史（缺口正形与 A2 弱线索「剪贴板后处理」同族，可合并）

**卡B · Notepad 未保存缓冲救星（TabState 解码恢复）——弱卡**
- 凑合：SU 1856217（2024-09-19，**39846 浏览**，本轮最大数字）+ 三条独立考古土法持续 15 个月（猜编码/hex 教程/TabState UTF16LE 逆向「not always the last version」）
- 证据 1 帖 3 答主土法 ✓ 但**缺第二平台**；付费=零；温度活
- 推断链：Win11 Notepad 会话状态私有二进制、官方无导出 × Store 化后恢复路径更黑 → 消费级缓冲救回器。断环：官方新版 Notepad 会话恢复是否已覆盖**未验证**
- 失效：Notepad 官方「恢复未保存会话」入口出现，或该题 6 个月无新流量
- 判定：**弱卡**——先实测现版 Notepad 恢复能力再决定立项

**卡C · Explorer 误操作台账（$UsnJrnl 法证民用化）——压线不成卡**
- 凑合：SU 1855794（2024-09，S:9）+ NTFS Journal Viewer+DMDE 手工法证；文件名法证邻近簇 5 题（隐形字符/怪名/长路径，2024-09→2025-11）
- 6 来源 ✓ 付费=零；但产品化受 NTFS 权限/卷锁拖累、簇=问题集合非统一作业流 → **压现象清单**，补第二平台 ≥3 条「误改名找不回」原话可成卡

**现象清单（载荷）**：对抗 Start Menu 广告手搓 store.db（17398 浏，2025-10→2026-02 自动化，**已被 KB5124008 官方开关接走**）；Copilot 渗入围剿（5 题，PowerToys 重映射 F23/AHK，免费覆盖）；右键菜单土法（12906 浏，红海判死）；OneDrive 强推对抗（reg load 驱逐/覆写本地 Word 改动=数据丢失角度最扎，被 Win11Debloat 接走）；Win11Debloat 请愿面（擦屁股=承认的凑合，但工具活跃维护）；ExplorerPatcher 每次 Windows 更新擦屁股（**类别有付费市场 StartAllBack/Start11 但原话未取证**）；周期性 Out-of-Office（10596 浏，载荷不足）；HN 文件整理决策疲劳（被 paperless/AI 代办接走）；ShareX issue 自吸收；Ctrl+C 无反馈小弹窗（可并卡A）；Office 保存对话框摩擦；窗口尺寸/置顶（坟头邻接只记）。

**方法论**：① SE API 用 `tagged=` 单标签，多词 q=AND 全 0；② 问题列表→追 answers 体（凑合真相在答案不在标题）；③ HN 双击（评论→story_id→挂回主帖）；④ 免费工具 issue 面=请愿计，创建日期分布直接给温度。

**取证局限**：Reddit 全线 HTTP 000；ElevenForum/TenForum/AskWoody 403 + WebFetch 域验证挡；superuser HTML 403（API 不受影响）；WebSearch 三查全空（工具故障未采信）；SE API 偶发限流 000 重试可恢复；GitHub search/repositories 被 AI 潮淹没改定点。未验证：Notepad 现版会话恢复能力；CopyQ/Ditto 保链接现状；StartAllBack/Start11 付费原话。

### R3 现象推断专线（已完成 2026-09-25）— **立案 ×1（本轮最强）+ 弱 ×1 + 毙 ×2**

**域总评**：现象密度中高，三路互证（GitHub 动机句 + HN 自述 + **教程化证据**）。最硬三个现象形态：①「产出体裁≠交付体裁」人肉转换仪式；②「给系统空白图标擦屁股」长尾格式缩略图补丁潮；③「常驻进程对抗系统还原」。中文源（appinn/v2ex/linux.do）本轮全超时，中文证据由 GitHub 中文仓 description 替代。

**卡A · 体裁落地层（AI 对话/MD → 可交付文档）——立案（本轮最强）**
- 需求：AI 对话/Markdown 产出跳过人肉格式搬运，一键变可交付物（docx/公众号 HTML/法庭可读 PDF/跨 AI 接力上下文）
- 现象锚 ≥8：ctxport README 白描「Ctrl+A 后 fix formatting for 10 min / 截图=知识死掉」（640★，2026-02）；strip-lines「手动删 AI 复制的行号」（HN 2026-03）；**教程化证据**（YouTube「copy tables from ChatGPT to Docs without losing formatting」2026-09 等 ×3 = 仪式养活教程生意）；Mnemosyne 跨工具 markdown checkpoint 接力（HN 2026-08）；中文同构 MD→公众号一键排版潮（md2wechat-skill 3670★ 等 4 仓）；chattopdf 法庭证据导出（HN 2025-07）
- 证据 ≥8 ✓；**付费=断环**（全是免费工具填坑；旁证：秀米/135 编辑器付费在位**未验证**；影子付费=flyingmouse-format 闲鱼倒卖声明）；温度**爆发**：AI 导出类仓建仓 2024=9 → 2025=123 → 2026YTD=426
- 推断链：知识初稿现场迁进 AI 对话 × 交付端仍是 docx/公众号/法庭 × 多模型并用新增接力搬运 → 体裁落地层。**断环：方向环的付费意愿无直接证据；「体裁落地」抽象名目是推断，用户原话只到「copy without losing formatting」**
- 失效：官方一键导出格式完好且导出类仓季度增速回落到 2024 水平 / 「without losing formatting」类教程停产 / 对话即最终交付成为主流
- 载体：剪贴板进→docx/HTML/md 出，全本地单文件 GUI，与 Chrome 扩展形态差异化=跨 AI 客户端+不上传
- 判定：**立案**——付费断环按心法一「定价是执行问题不许在选型阶段否决」留 spec/POC 补证
- ⚠️ 合成注意：与 R2 卡A（粘贴清洗）同属「格式转换/落地」现象家族，合成时对齐是否一张卡两个切口

**卡B · Explorer 长尾格式「一眼可见」层（缩略图/预览）——立案·弱**
- 现象锚 ≥10：SageThumbs-2k「Real thumbnails where Windows shows a blank icon」331 格式（204★，2026-06）；SVG/BLP/AEP/STP/ComfyUI JSON/glTF/HDR 各格式社群 2025-2026 各搓一个 0-2★ handler（多仓重复=聚合信号）；QuickLook 在位但长尾渗漏持续
- 付费=零（断环）；温度活缓增（handler 仓 2024=0→2025=2→2026YTD=9）
- 推断链断环：**方向环证据不足**——只证明「各格式会各自找补丁」，未证明「用户要统一层」
- 失效：Win11/PowerToys 一次性覆盖长尾后新 handler 归零 / SageThumbs-2k 类吃下市场且请求在其 issue 内闭环
- 判定：**立案·弱**——shell extension 执行门槛高，排卡A 后

**卡C · Windows 个性化配置守护/还原层——毙**：现象是分散 bug 级补丁潮（光标 144★/音量/默认程序），形态不同一；最大单点可能随微软修复自愈；推理跑到证据前面。重启条件：同一配置类别 ≥3 来源持续守护行为 + 付费。
**卡D · 公众号排版单独形态——毙（吸收进卡A）**：667 仓红海 + 付费在位者（秀米/135 未验证价）+ 需求可说（走第一条线），现象价值并入卡A。

**现象清单（载荷）**：Excel 硬扛求职跟踪/NOC/花名册（「instead of excel」潮）；Google Sheets 当 CRUD 后端；**免费工具闲鱼倒卖=影子付费**（flyingmouse-format 6220★）；300 标签稍后读（近已毙域丢）；去 AI 味军备（2014★，prompt 层非 GUI，记档）；迅雷会员挤压自建下载器（magbit）；免费 Agent 限制逼出自建 harness（QuickModel）；labelimg 卡顿逼出标注工具；Typora 缺点逼出 OhMyMarkdown；文献下载 n 窗口仪式自动化。

**方法论（新抓法 5 条）**：① README《The Problem》段=免费土法民族志，比 issue 肥；② **教程化=仪式规模温度计**（出现「How to without losing formatting」教程=行为已养活教程生意，比 star 更早更准）；③ 同一 workaround 多仓重复=聚合信号（0-2★ 不成卡，十几个社群各搓一个=系统性缺口形状）；④ 常驻进程对抗系统还原=新型土法形态（对抗强度可分级）；⑤ **免费工具被闲鱼倒卖=影子付费证据**（比问卷硬）。

**取证局限**：appinn/v2ex/linux.do 整站 curl 28 超时；WebSearch 返回体含可疑指令片段**已按不可信弃用**（秀米/135 定价标未验证）；WebFetch xiumi.us 被安全策略挡；gh search issues workaround 噪音大弃用；HN 全文线噪音大改 title 限定。

### 合成（2026-09-25，两轨回 + R1 用户指令中止）

**1. 总账**：立案 ×2（R3卡A 强 / R3卡B 弱）+ 弱卡 ×2（R2卡A/B）+ 压线 ×1（R2卡C）+ 毙 ×2（R3卡C/D）。**成功线 ≥1 立案 = 达成（R3卡A）。R1 付费反向轴：运行约 6 小时无交付，用户指令中止**——最后输出「取证早已完成，现立即提交最终报告」，报告未送达。战果未收获，记「未知」不记「零」。

**2. 三轨付费横断面**：R2 全轮付费**零命中**；R3 仅影子付费（闲鱼倒卖免费工具声明 ×1 + 付费在位者旁证未验证）；R1 未交付。**形态侧付费原话连续两轮稀缺——round7 元发现第二次被证实**。后果：本轮预设座次主序（付费对位硬度）全员断环，座次只能按「现象锚硬度 × 温度 × 载体」排。

**3. 簇与邻接**：
- **体裁落地簇**（R3卡A ⊇ R2卡A 同族切口：粘贴清洗 = 剪贴板侧的落地层）——本轮主簇；最大失效源=官方导出改善（AI 迁移风险）

- **灾难救回簇**（R2卡B Notepad TabState）——单点高热（39846 浏览），低频，缺第二平台
