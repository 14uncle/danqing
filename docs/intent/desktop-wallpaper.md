## 一、Statement of Intent（用户确认稿）

- **Outcome：** 做一款 Windows 桌面壁纸工具，先平替拾光壁纸的核心体验：不用自己找图，能自动获得质量稳定、符合审美的壁纸。
- **User：** 首先服务十四叔自己；是否适合更多人、能否收费，由后续调研验证。
- **Why now：** 用户每天都在使用壁纸产品，但目前要靠每天点赞攒使用天数来避开付费。
  - **2026-11-02 用户确认**：实际做的是官方**签到**（每天 1 点）。30 天签到 = 30 点 = 30 天订阅，免费层可长期维持，故真实痛点是**维持权益的每日仪式**，不是价格。产品（或脚本）要消灭的是这个仪式。
- **Success：** 用户愿意持续使用丹青版，不再打开拾光壁纸，也不再打卡攒天数；能找到差异化或付费点则加分。
- **Constraint：** 产品长在 danqing 引擎上；先按选型指南完成需求、竞品、定价与系统吸收距离调研，再决定是否进入 spec，不直接开写。组合纪律独立有效：若裁决继续，开枪前仍须确认当前活跃产品已发布/终止，或由用户明确调整队列/给予豁免；「自用」不自动豁免。
- **Out of scope：** 首版不做壁纸编辑器、社区/账号体系、动态壁纸引擎和移动端，也不为了收费硬造亮点。

## 二、访谈得到的行为证据

- 用户本人每天使用壁纸产品，认可拾光壁纸的核心体验。
- 用户通过「每天点赞积攒使用天数」绕过直接付费；这是带日常仪式的真实绕道行为，但只证明用户本人的需求与价格敏感，不外推为市场需求。
  - **红队修正（待用户确认）**：官方现行获点路径是赞助、看广告、**签到每天 1 点**与评分等活动，未核到「点赞换天数」；30 天签到 = 30 点 = 30 天订阅，故免费层可长期维持。若用户所指即签到，则真实痛点是**每日仪式**，不是价格。
- 商业化优先级：能形成丹青特色与收费亮点最好；做不到仍允许成为自用工具，不以付费亮点作为开枪前提。

## 三、情绪价值假说与拾光一手补证（2026-11-02）

### 用户提出的第一性原理

壁纸提供的是情绪价值；能给予心灵安抚的对象因人而异，可能是一本书、一部电影、一座城市或一个人。由此提出候选方案：通过关键词获得对应图源，并核查它能否支撑付费、竞品是否已做。

这条假说必须拆成三环分别取证，不能一次跳过：

1. **情绪需求**：人们是否主动为情感对象搜图、收藏、持续轮换或付费。
2. **方案匹配**：关键词/主题是否真能持续提供合意图片，而非只返回泛化库存图。
3. **付费成立**：该能力是否仍有免费替代品未满足的缺口，且有人为它掏钱。

### 拾光实机截图（用户提供的直接竞品证据）

- **已有 100+ 预设专题**：不只是风光/城市等宽泛分类，已覆盖具体作品、IP、艺术家与情绪场景，如沙丘、宫崎骏、星际穿越、你的名字、WLOP、NASA、城市光影等。故「按情绪对象分主题」已被在位竞品实现，不能独立作为丹青差异化。
- 官方 gallery（用户给出 `https://gallery.timeline.ink/`）顶栏有专题图集、图源列表、最新、趋势、随缘、我的收藏、为我推荐。
- 页面明示：「**暂未开放语义搜索，你可以暂且通过关键词查找心仪的专题内容**」。这里的已知能力是关键词查找已有专题内容，不等于用户可用任意关键词创建持续图源；语义搜索未开放也不自动等于需求空位。

### 修订后的研究问题

真正待证的不是「壁纸有没有情绪价值」，而是：**任意自定义对象 + 围绕该对象持续稳定供稿 + 结果合意**，是否仍有人绕道或付费。预设专题、一次性图库关键词搜索、语义搜索和偏好推荐必须分开比较。

## 四、调研任务与取证纪律

1. **拾光与中文竞品**：核心体验、收费机制、点赞攒天数规则、免费限制、用户缺件与绕法、近两年的版本/讨论日期分布。
2. **海外竞品与 open issues**：静态自动换壁纸与相邻产品逐项扒；功能缺口、用户原话、反应数、issue 创建日期分布；免费在位者不能漏扫。
3. **需求与付费验证**：寻找仍在绕道、手工找图、写脚本、抢救免费工具或为壁纸产品掏钱的人；言词抱怨和 star/下载量不单独算需求。
4. **定价调研**：竞品定价区间、付费权益、用户付费态度，与农场买断产品线的一致性。
5. **系统吸收距离**：Windows Spotlight / Bing Wallpaper / 免费开源工具距核心体验多远，18 个月内被平台顺手做掉的概率。
6. **图源与版权**：自动供图的来源、API 条款、下载/缓存/再分发限制与成本；不得把不可持续图源当核心壁垒。
7. **丹青适配**：框架可复用能力、可能形成的视觉/交互差异、缺口与粗工时；引擎复用是实现约束，不反推需求。

### 需求验证回卷（独立研究路，2026-11-02；待红队复核）

**阶段结论：「仍有人为静态壁纸付出持续劳动」有多源行为证据；「任意情绪对象 + 关键词持续供稿」未证明付费需求。更贴近现象的是「免费图很多，但稳定符合个人审美仍费时」，不是「找不到图」。**

**反证与断环：**

- 系统聚焦已让一部分用户满意；自动换静态图本身不是普遍缺口。
- 任意对象、情绪价值和持续供稿三环均缺少终端用户的近窗一手付费/绕道证据；开发者做出功能不等于用户需要。
- 固定书/电影/人物的合规新图可能有限，持续供稿容易变成重复、泛化或 AI 生成；窄关键词池也会枯竭。
- 当前最稳妥的需求表述应改为：**为已经对免费图库/系统推荐不满意的人，降低长期挑到合意静态壁纸的成本。** 任意对象必须与预设专题做对照，不可直接当付费钩。

### 中文竞品与拾光回卷（独立研究路，2026-11-02；待红队复核）

#### 拾光的真实能力/收费边界

- 官方身份：开发者 `nguaduot / 南瓜多糖`；[官网](https://timeline.ink/)、[网页图库](https://gallery.timeline.ink/)、[免费商店版](https://apps.microsoft.com/detail/9n7vhq989bb7?hl=zh-CN&gl=CN)、[Pro 商店版](https://apps.microsoft.com/detail/9n4g18ndvgp3?hl=zh-CN&gl=CN)。官方 FAQ 明确只做静态壁纸、无动态壁纸计划；公开 GitHub 停在 2023，不得把现行 28.x 称为当前开源。
- 现有 30+ 图源、100+专题；[官方更新日志](https://doc.timeline.ink/#/changelog-windows) 2025–2026 仍密集。浏览和手动设壁纸免费；在线自动换图、每日推送、为我推荐为赠点/订阅权益。
- **公开图库 API**（红队补记、主会话实测）：[图片接口文档](https://doc.timeline.ink/api-image.md) 开放 `/{provider}/v4|today|random|cate`，示例 key 可用；`/bing/today` 实测 2026-11-02 返回成功。自用自动换图的最低成本因此降到「一条请求 + 一次壁纸写入」。
- **内容权利**（红队补记、主会话复核）：「拾光所有图片均为免费开放，非商业用途……请勿用于商业用途，拾光不会也无权提供商用授权」。故其赞助收入不能当「精选付费可复制」的合法性或商业证据。
- 任意关键词完整图片搜索、语义搜索、把关键词保存为自定义持续图源：**均未支持**。固定专题可自动轮换；本地图库轮换免费，在线图源自动轮换收费。[搜索文档](https://doc.timeline.ink/#/search)、[自动更换](https://doc.timeline.ink/#/push)、[推荐设计](https://doc.timeline.ink/#/seek)。
- [账号规则](https://doc.timeline.ink/#/account)：在线自动换图/推荐 **30 点/30 天、150 点/180 天**；赞助 ¥1 赠 10 点，名义折合约 **¥3/30 天、¥15/180 天**；原图下载 1 点/张。Pro 商店结构化报价 **¥88 买断**，含在线自动换图、下载不扣点、推荐和去广告。
- [官方活动](https://doc.timeline.ink/#/activity)可核签到、广告、商店评分、协助标图等赠点路径；**未核到「普通壁纸点赞固定换天数」的官方条文**。用户每天点赞/互动攒天数是一手使用事实，具体对应哪项官方机制待对齐，不擅自改名。
- 官方接口在研究路 2026-11-02 11:31 快照自报 **30,143 位赞助者 / 35,501 次赞助**（[名单接口](https://api.nguaduot.cn/appstats/life/sponsor)、[汇总接口](https://api.nguaduot.cn/appstats/life)、[致谢页](https://timeline.ink/about/thank)）；**主会话 12:32 复核已增至 30,144 / 35,502**，年份分布 2024 年 10,178、2025 年 12,177、2026 年至 11-02 为 7,326。该数据未审计，金额/ARPU/付费率不可推算，赞助动机也不能归因到任意关键词；但它支持「精选壁纸 + 自动供稿有现实付费」。

#### 行为证据与付费归因

- Windows 聚焦故障有 [2025-08-23 Microsoft Q&A](https://learn.microsoft.com/zh-cn/answers/questions/5532042/win11-windows)（73 票、9 回答，后续用户清缓存/重置组件），说明免费系统源的稳定性会让人投入排障劳动；不等于愿为另一软件付费。
- [2025-12-13 wallPaperSwitcher](https://github.com/yige233/wallPaperSwitcher) 作者因找不到「自定义 Web/API 图源 + 原生幻灯切换」而手搓，2026-06 仍更新；证明技术用户的自定义源行为，不证明普通用户规模。
- **未找到近两年 ≥3 个独立来源，证明用户因拾光缺任意关键词/缺专题/专题更新慢而持续绕道或付费。** 任意关键词作为付费核心未过需求闸。
- 用户愿每天互动换取名义约 ¥3/30 天的在线自动换图，是强使用证据，也是直接价格敏感证据；不能把「每天用」写成「愿付费」。

### 平台与内容供应回卷（独立研究路，2026-11-02；待红队复核）

**阶段结论：通用「每日高质量静态图」已被系统吸收；「关键词可查询」与「可合法持续商用供稿」之间有硬断环。**

#### 系统吸收距离

- Windows 11 桌面 Spotlight 已原生每日换静态图（[微软配置文档](https://learn.microsoft.com/en-us/windows/configuration/windows-spotlight/)，研究路记录页面更新 2026-02-20；**主会话 2026-11-02 已复核原句**「Windows spotlight displays a new image on the lock screen and in the background every day」）；[Bing Wallpaper](https://www.microsoft.com/en-us/bing/bing-wallpaper) 亦提供每日桌面新图。通用能力距系统不是「18 个月一个 checkbox」，而是**现在已经一个下拉/一次官方安装**。
- 本地文件夹幻灯片已解决自有图片轮换，第三方价值只能在「选什么」，不能在「怎么轮换」。
- PowerToys [#1352](https://github.com/microsoft/PowerToys/issues/1352) 已以「Built into Windows」关闭；[#42776](https://github.com/microsoft/PowerToys/issues/42776)（2025-10-22）再次请求后被指回 Bing 团队。没有证据支持 PowerToys 再做一套通用每日壁纸。
- Microsoft Photos 在 Copilot+ PC 已有本地照片语义搜索、文字生成静态图和照片重绘（[搜索照片](https://support.microsoft.com/en-us/windows/apps/photos/search-photos)、[生成/重绘 FAQ](https://support.microsoft.com/en-us/windows/ai/ai-apps/microsoft-photos-restyle-image-and-image-creator-responsible-ai-faq)）；尚未核到官方「每日自动生成壁纸」承诺。生成/重绘需特定硬件、联网和微软账号，不能当全量替代。

#### 对情绪关键词方案的约束

- **具体 IP/当代艺术家/人物**：海报、剧照、角色立绘、封面、摄影作品均不是「搜到即可再分发」；竞品已有专题不证明其授权状态，也不构成后来者合法先例。通用城市/自然/色彩较易建立合法供应，具体作品需权利人授权或转为不复制受保护表达的通用意象。
- **本地个人照片**：在用户显式选择正向集合时，情绪关联、离线和权利链最可控；但数量、新鲜度、横屏质量不一，且自动扫描可能翻出负面记忆或他人隐私。它是转向候选，不是已验证需求。
- **较稳供应链**：用户自有照片、逐资产审核并固化许可元数据的 CC0/公有领域库、直接签约/委托创作者。公网 API 只能在许可允许时作发现，不可把每次搜索结果直接设为壁纸。

**选型含义：** 「无账号 + 自动换好图」没有平台护城河；「任意关键词公网供稿」同时遭遇免费替代与授权断环。若后续考虑「私人记忆 / 公共领域艺术策展」转向，必须重新过需求证据，不得借供应链可行性偷偷完成选型。

#### 事实修正（主会话已复核前三项）

1. **「点赞攒天数」疑为机制误记**：官方只有赞助赠点、看广告每次 2 点、**签到每天 1 点**、评分等活动获点（[账号规则](https://doc.timeline.ink/account.md)，主会话已复核原文）。30 点订阅 30 天、150 点订阅 180 天，故 30 天签到即 30 点，**免费层实际可长期维持**。用户所述「每天点赞」与哪项官方机制对应，须用户本人确认；在确认前，Why now 里的「为避付费」应降级为「为维持使用权益的每日仪式」。
2. **拾光公开图库 API 真实可用**（文档此前漏记）：[图片接口文档](https://doc.timeline.ink/api-image.md) 提供 `/{provider}/v4|today|random|cate`；主会话用文档示例 key 实测 `https://api.nguaduot.cn/bing/today?json=1`，**正常返回 2026-11-02 每日图与直链**（`timeline/v4` 另需设备 ID，返回「设备 ID 缺失」）。这意味着「自用自动换图」可在一日内实现，供应链瓶颈不是「找不到图」。
3. **拾光内容权利状态**（文档此前漏记）：官方明写「拾光所有图片均为免费开放，非商业用途……请勿将拾光所分享图片用于商业用途，**拾光不会也无权提供商用授权**」（[账号/关于页](https://doc.timeline.ink/account.md)、[使用协议](https://doc.timeline.ink/terms-of-use.md)，主会话已复核）。它抽掉了「把精选内容另做商业平替」的合法性前提，也说明拾光的赞助收入不是「可复制的精选付费」证据。
4. **Pixabay 被过度解读**：条款禁的是 **Standalone 分发**（点名 print/wallpaper/poster），不是禁止壁纸应用本身；带署名、不作图库再分发的展示型应用风险低于本卷原表述。
5. **wallpapi 证据力被高估**：issue #1 由仓库 **OWNER 自己**在 2026-09-24 建仓当日开、当日关闭，1★；是作者自己的 epic，不是用户声音。
6. **黑猫三条投诉不可复现**：URL 只返回壳页，正文取不到，不作裁决依据。
7. **赞助数解读需收紧**：35,504 次 / 30,146 人 ≈ 人均 1.18 次，且激活账号本身需赞助，故更接近「历史激活账号数」，不是当前付费用户、ARPU 或付费率。
8. **Pro ¥88「含自动换图/下载不扣点/推荐/去广告」未核**：只核到结构化价格 ¥88 CNY（商店标价 99）。

#### 成立攻击（按杀伤力）

- **A｜需求主体只有一个人，且其显示性偏好是「不花钱」。** 3 万赞助者是拾光的**留存**，不是替代品需求；五条行为证据全是开发者自述/自动化 Bing/本地轮换，没有一条是「我想离开拾光」。命题已被悄悄放宽成不可证伪的「降低长期挑选成本」，而施工对象仍是拾光克隆。
- **B｜没有付费楔子。** 拾光签到即长期免费，Bing/Spotlight 一次安装，backiee/JBS 免费；「免打卡/免账号」对唯一已验证用户的价值接近 0（他宁花时间不花钱，而他省下的时间正是要卖的东西）。
- **C｜结构错配：壁纸是内容运营，不是工具。** 每日策展、托管、法务、客服是永续成本；一次性 ¥18–28 养不起，订阅又撞农场「奶牛禁令」。15–25 人日只够客户端，不够一年运营。
- **D｜自用逃生舱使选型失去证伪力。** Success 写的是自用标准，失效标志却全是市场级；两套标准并存，任何市场证据都能被「反正是自用」吸收。且若底线只是自用，正确产物是 **≤1 天脚本**，不是 15–25 人日产品——成本尺度错配。
- **E｜跨路双标。** 用 ToS 否掉 Splashy，却拿同样无权商用的拾光收入当需求证据。合规应只作「我们能不能做」的约束，不作需求证据；需求侧只问有没有人在绕道/掏钱。
- **F｜粗算分母错误。** 用日志查看器的 1.1 浏览/天、4.1 uniques/天当壁纸类基准是类别错误；且漏了带宽/托管、策展工时、授权/委托、法务、商店抽成。「赚不到钱」的结论可能仍成立，但不能靠这个数支撑。

#### 红队认可的部分

事实没有编造，日期价格基本对得上；「通用每日图已被系统吸收」「公网关键词供图有法律风险」「拾光只有固定专题、无任意关键词持续供稿」三条成立。

## 五、引擎与内容资产初查（2026-11-02，本机源码）

### 可复用

- `danqing/src/lib.rs` 已公开 `AsyncJob` / `CancelToken`、`startup`、托盘与全局热键、`Theme`、`BackgroundConfig` / `ImageBatch`；`persist` feature 提供配置目录、原子写与版本化持久化，`update` feature 带系统证书库的 `ureq` 运输可参照。
- 自绘 UI、明暗主题、图片缩放与双槽纹理 LRU 已有，壁纸浏览与收藏界面不需要新造 UI 基座。
- 已有多张场景底图及生成/迭代记录，可作审美方向的种子，不可直接当作可售内容库。

### 缺口

- 全 `danqing/src` 无 wallpaper / `SystemParametersInfo` / `SPI_SETDESKWALLPAPER` 实现：Windows 壁纸写入是新平台肌肉；逐显示器设置、显示器变更与 DPI/比例适配需单独验收。
- `Cargo.toml` 的 `image` 仅启用 PNG；主流图源 JPEG/WebP 解码要补 feature 并实测。通用下载、缓存、配额、失败重试与内容元数据也不是现成产品能力。
- 场景底图由元宝等 AI 工具生成（`docs/CONTEXT/ai-image-prompts.md`），当前为 **1536×1024、3:2**；对 16:9 / 高分屏不是开箱即用的高清壁纸，生成工具条款与商业使用/再分发权尚未核查。不得写成「原创高清壁纸库」。

### 对差异化的约束

「用了 danqing / UI 好看」不是需求证据，也不是收费点。可检验的丹青特色只能落在：稳定的策划审美、统一场景系列、符合桌面图标可读性的构图、无打卡/无账号/本地掌控，以及竞品仍未满足的具体行为缺口。 shader 动效属于明确排除的动态壁纸路线，不得偷渡回首版充当差异化。
