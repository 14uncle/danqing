## 产品形状（抄自 deep-dive-round8-t1 §合成，被三轨证据塑形的最终形状）

- **主腿：中文 AI 对话/MD → 公众号 HTML 一键落地**——剪贴板进（纯文本 MD + CF_HTML 富文本双路）→ inline-CSS 公众号 HTML 出（用户自己粘进公众号编辑器）+ 排版预览 + 约 3 套模板。
- **次级腿：对话/MD → docx**（服务 ChatGPT/DeepSeek/豆包用户；Claude 用户已被官方接走，不为其做）。
- **v1 砍**：PDF（老需求饱和 + printpdf 成本高）、直推草稿箱（公众号开发者凭据 = ToS 灰区；止步剪贴板 = 合规干净 + 形态差异）。
- **添头**：跨 AI 接力上下文导出（md 摘要，成本近零）。
- 引擎适配：剪贴板 HTML 双路读现成（技术楔子）；MD 解析用 pulldown-cmark、HTML 用 scraper；docx 用 docx-rs（无协议逆向）；排版预览 widget 新建 2–3 人日；v1 总估 15–20 人日。
- **付费层未定**：¥25 买断仅记账口径；粗算直接收入期望≈0（如实）。v1 是否带付费层、还是照探针 b 免费层先行——**spec 锁定时呈用户裁**（可参考 Drop Shelf v1 免费铁三角 + 农场「免费层即仪器」定位；环2 三中二即杀失效标志无论哪条路都进发布埋点）。

## 三路合成（2026-10-09，三路齐后回填）

**1. 座位终判（三路互证）**：余下空位 = **「公众号 HTML + 中文场景 + 离线桌面」交集**。
- 独有×3（R2）：剪贴板双路输入（MD+CF_HTML）九家全空 / docx 输出真空白（26 README 0 命中）/ 跨 AI 零绑定（剪贴板是唯一 client-agnostic 口）。
- 桌面缝实证（R1）：wenyan 系桌面复制按钮「时能用时不能用」、桌面不支持自动上传本地图片——桌面形态的「办利索」位没人占。
- 头号痛点（R1）：粘贴到公众号掉样式（多人复现、维护者承认保存时剥样式）——「预览所得 ≠ 公众号所得」。

**2. 形状修正（进 spec 的硬约束）**：
- **验收 = 实机粘贴对照**（预览所见 = 公众号所得），不许只验自家预览。
- **模板硬约束**：零渐变、零 @media、暗黑双主题过检（微信「内容结构检测」+ Dark Mode 强制转换 2026-09 上线，渐变=每篇手动点继续）。
- **剪贴板双路写 + 自读回校验**（桌面复制失效教训进硬条款）。
- UTF-16 LE 导入处理（wenyan#22，正中 danqing-encoding 肌肉）。

**3. 风险座次改判**（取代 deep-dive §补环风险清单座次）：
1. **skill 形态替代 + 官方 harness 化双面夹击**（新头号；gzh-design-skill 复活两周 +114★、md2wechat 主推推送草稿箱、豆包/DeepSeek docx 面实锤、Claude Docs/Google Workspace 内化中）
2. 中间位挤压（人群厚度未证，维持）
3. 形态付费断口（环1 终判=断，维持披露；判据①已废，唯一裁判=首单外检）
4. 平台依赖（微信编辑器规则；结构检测+Dark Mode 即最新一击）
5. 微信生态内免费化信号（维持）
6. 付费层分发没着落（维持）
7. 收入泄漏/倒卖（flyingmouse 路径，新入列）
- **风险⑤豆包盲区销案**（已实锤；伤 docx 通用腿，不伤公众号主腿）。

**4. docx 腿重定位提案**：从「通用交付物」（撞 Anthropic/豆包官方火力）→ **「公众号素材库 docx 载具」**（wenyan#36 原话：素材库防盗链，docx 导入是 workaround，2025-08）——落在公众号半区内，避开官方通用 docx 火力，且与图片问题合流（图片随 docx 进素材库）。

**5. 独缺 N 清单处置提案**：直推草稿箱 v1 不进（ToS 灰区，写风险清单）；长图导出 → v1.x；图床/图片上传 v1 不做（零后端架构），图片保真传递 + docx 载具承接；N5 Word/PDF 输入归一化 → v1 可选件。

**6. spec 前必做**：豆包/DeepSeek docx 导出保真人工实测（要动用户机器/账号，待点头）。
