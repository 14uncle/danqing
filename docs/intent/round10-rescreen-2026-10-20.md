- 证据：
  - `deep-dive-round9-t1-2026-10-09.md` §D2（2026-10-09）
  - https://github.com/iamzubin/holdem

**Gate 2 需求真实：失败（严格口径）。**

- 免费全链在位者已覆盖「收 → 暂存 → 一次拖出」：
  - DropPoint 1094★（pushed 2026-08-04，末版 release 2022-09-12）
  - Edge-Drop 632★（v0.3.2，2026-09-26）

- 红队 A2（2026-10-09）判定：「缺中转暂存架」的需求表述被免费全链证伪；真活证据只剩「买后缺 Y」。

## Phase 4 · 过闸候选的调研三闸（Task 9）

### 候选 1 · A3 iPhone 备份

**裁决段：放弃（本轮）。**

依据：需求与付费证据真（5 DIY 仓连续 + iMazing 付费在位），但利基窄、系统吸收近、粗算不成立；当前农场不缺「又一个零收入小工具」。

**红队（doubt-driven）：**

1. **付费形态不对位**：iMazing 是全功能 iOS 管理器，不是「照片备份」单点；3 笔买断自白买的不是拟做形态。
2. **系统吸收**：Apple 修 Windows 端或 MS Photos 修导入 → 需求消失（失效标志已写死）。
3. **技术依赖**：`pymobiledevice3` 是 Python 生态，Rust 产品需 FFI/子进程，维护面扩大。
4. **用户会自己造**：5 个 DIY 仓 = Gate 1 的反证；3uTools/iMazing 免费层已覆盖大部分场景。
5. **人群交叉窄**：iPhone + Windows + 在意照片备份 + 愿为单点买断，四重交集。

**一页粗算：**

| 项 | 数 | 依据 |
|---|---|---|
| 渠道可见流量 | 月 50–150 商店展示 + 200–500 GitHub/内容浏览 | 农场第一方实测（pomodoro 46 展示/月；log 14 天 180 views） |
| 转化 | 0.1–0.5% | 8 渠道 ≈570 阅读→24 安装→0 付费 |
| 单价 | ¥29–49 | iMazing 邻价；农场买断区间 |
| 月收入期望 | ≈¥0–37 | 上限 150×0.5%×¥49 |
| 工时 | 15–25 人日 | 移动设备协议 + GUI + 备份事务 |

**结论：放弃/挂起，不进 spec。**

### 候选 2 · A4 多显示器管理

**裁决段：放弃（本轮）。**

依据：需求与付费硬（3 笔买断自白），但 DisplayFusion 功能护城河深、Win11 内化风险高、单人难做出差异；粗算不成立。

**红队（doubt-driven）：**

1. **形态对位弱**：3 笔自白买的是 DisplayFusion 全功能，不是「轻量多显示器管理」。
2. **系统吸收**：Win11 逐屏任务栏 / 原生窗口位置 profiles 持续内化（失效标志两条）。
3. **PowerToys 补位**：profile 管理被第一方工具箱收走的概率不低。
4. **用户会自己造**：AHK 手搓潮 = Gate 1 反证。
5. **功能广度打不过**：单人只能做窄切口，而窄切口的付费证据未单独成立。

**一页粗算：** 同上（月 50–150 展示 + 200–500 浏览；转化 0.1–0.5%；单价 ¥29–49 → ≈¥0–37/月；工时 15–25 人日）。

**结论：放弃/挂起，不进 spec。**

## Phase 6 · 新扫候选的调研三闸

### 候选 1 · 字体库管理

**裁决段：放弃（本轮）。**

**红队：**

1. **TAM 窄**：MainType 免费版覆盖 2,500 字体、Standard $49 覆盖 10,000；只有 50k+ / 多工作站用户才痛，而这批人已被 MainType/FontBase 覆盖。
2. **竞品会修**：FontBase 2026.7.0 的 12.8 万崩溃是版本 bug，不是永久缺口；修复即失效。
3. **维护面深**：Adobe/Office/Corel 自动激活插件与版本强耦合；Windows 字体库操作容错极低。
4. **渠道错配**：设计师聚集在字体/设计社区，农场现有渠道（GitHub/小众软件/MS Store）触达弱。
5. **付费证据中**：MainType $49/$79 是长期在位价，不是新买家对「新工具」的付费自白。

**一页粗算：** 月可见流量 100–500（设计社区 + 商店）；转化 0.1–0.5%；单价 ¥199–399 → **≈¥20–1,000/月**；工时 20–30 人日。

**结论：放弃/挂起，不进 spec。**

### 候选 2 · 赊销单据/欠款台账

**裁决段：放弃（本轮）。**

**红队：**

1. **渠道是死穴**：买家在乡镇门市，农场现有渠道触达≈0；要靠抖音/本地地推，而这条分发路径农场没有。
2. **免费在位者贴脸**：蓝橙、小灰狼等送货单打印免费/绿色版；智慧记免费版含欠款。付费理由必须强到「证据链 + 打印 + 本地备份」三合一。
3. **移动优先**：赊账记账类 App 密集；桌面可能是错载体。
4. **价格天花板**：¥298 终身已是送货单工具顶价；单人带宽难覆盖持续维护。
5. **法律责任**：电子欠条未必被法院直接采信，产品只能定位「证据整理」，不能承诺法律效力。
6. **数据责任**：账本是命根子，一次损坏就是灾难。

**一页粗算：** 农场渠道可见流量 ≈0–50/月（触达不到目标人群）；转化 0.1–0.5%；单价 ¥298 → **≈¥0–75/月**；工时 20–30 人日。若要触达，需另建抖音/本地渠道，成本另计。

**结论：放弃/挂起，不进 spec。**

## Phase 7 · 最终结论（2026-10-20）

- 复审 12 条 + 新域扫描 5 张卡 = **17 条**。
- 过三道闸：A3、A4、字体库、赊销单据（4 条）。
- 调研三闸后：**全部放弃/挂起**。
- **本轮最终：判无——零可开工候选。**

**为什么全是「需求真、生意不成立」？** 因为卡住的是同一个乘数：**渠道可见流量**。农场第一方实测 ≈570 阅读→24 安装→0 付费；新扫出来的两条最强卡，目标人群（设计师 / 乡镇门市）都不在农场现有渠道里。换产品解决不了这个乘数——这与此前 09-20 调研的结论一致。

**下一步（归用户）：**

- **B · 停选型**：带宽转分发 / 收银台 / log v1.x 收尾。
- **C · 先修分发**：不改产品，先建一条能触达目标人群的渠道（内容/短视频/垂直社区），再用同一闸门重扫。
- **D · 廉价探针**：对字体库或赊销单张卡做假门测试（落地页 100 UV 留邮箱），读数过线再谈 spec。
