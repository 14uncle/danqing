# round11 广域扫描 · 100 泳道（2026-10-20）

> 用户指令（2026-10-20）：「再选型，10 批不够，你筛 100 批，你不是能联网吗？把网撒宽一点，深一点，实在没有捞到候选，最后来一轮用户行为分析推断出来可能解决方案（交互方式），毕竟用户想象力是有限的。」
> 本卷 = 执行计划 + 扫描台账。闸门沿用 round10 新判据；不复审已判死条目。

## 一、目标

- **A**：在 100 条泳道里捞出至少 1 个「agent 吃不掉 + 需求真实 + 陌生人掏钱」的候选。
- **B**：若 100 条全空，转**行为推断轮**——从现象推断需求，给出可能的交互方式，不再只找现成产品。

## 三、闸门（沿用 round10）

1. **Gate 1 · agent 吃不掉**：用户已有 Claude Code / 豆包 / WorkBuddy，为什么还买？
   - 可接受：A 想不到有这个解法；B 做得出但审美/调试/维护成本 > 售价；C 不敢信自造。
   - 死刑：核心价值 = 一次转换/生成/搬运；一次性输出；一个提示词可得同样结果。
2. **Gate 2 · 需求真实**：≥3 独立来源、近两年、带日期；行为证据优先。
3. **Gate 3 · 陌生人掏钱**：买断自白 / 付费竞品真实销量或评分量 / 为邻近品掏钱。star、下载不算。

**死池/已判条目**（命中一行带过）：clipboard 商业化、xirang、disk、tile、dropshelf、luoban、pomodoro、log 家族（含 plainsight）、自动平铺、磁盘分析、CSV 编辑、文本扩展、明暗切换、归档、步骤记录器、重复文件、本地照片、Screen-Studio、大文件编辑、hex、字幕、自动文件整理（Hazel）、多显示器、iPhone 备份、物格、徒弟、采访员、自传、主张器、预演台、微信归档、字体库、音乐样本库、个体户流水、赊销单据。

## 四、执行波次

- **Wave 1**：域 1–10（50 泳道），10 agent 并行，每 agent 5 泳道，75 分钟硬盒。
- **Wave 2**：域 11–20（50 泳道），10 agent 并行。
- 每 agent 输出：5 条泳道各一行结论；最多 2 张候选卡；零候选合格。
- 合成：主台账按 Gate 1→2→3 复核；过闸者走调研三闸（裁决段 / 红队 / 粗算）。

## 五、零候选 fallback：行为推断轮

若 100 泳道全空，开一轮**用户行为分析**：

1. 收 20–30 个行为现象（土法仪式、绕道、在错工具里硬扛、为邻近品掏钱、给免费工具擦屁股），带 URL + 日期。
2. 每条写推理链：**现象 → 本质 → 什么在变 → 方向**；哪环没证据哪环断。
3. 每条写死**失效标志**。
4. 从推理链推导**交互方式**（不是功能清单）：新的操作关系、新的信息呈现、新的工作流位置。
5. 产出候选交互卷，交用户裁决；不直接进 spec。

## 六、产出

- 本卷：Wave 1/2 扫描摄取 + 合成 + 最终裁决材料。
- 若零候选：行为推断卷（可另立 `round11-behavior-inference-2026-10-XX.md`）。

### 卡 1 · 大结果集数据库工作台（域1）

- **需求**：打开 5000 万行表能立刻滚动/筛选/改单元格，而不是等 45 秒、调 6GB 堆、退回命令行。
- **凑合证据**：TablePlus 付费用户 ClickHouse 1 亿行预览 85 秒无响应、作者退款（2025-05-13，#3592）；TablePlus 维护者承认行加载在主线程（2024-02-25，#194）；批量编辑 40–50 行冻结数年（2024-03-05，#3239）；DBeaver 15 万行导出卡死（2025-04-29，#37900）、静默截断（2025-02-17，#37214）。
- **付费**：TablePlus Basic $99 / Standard $129 买断（2026-10-20 实抓）；付费用户 issue 实证。
- **Gate 1**：活（A+B）——用户已不信 GUI 能快；多驱动流式游标 + 虚拟网格 + 就地编辑的维护成本 > 售价。边界：不能卖「会写 SQL」。
- **红队（域6 提出）**：2026 免费 Rust/Tauri 客户端成潮（DBX / DataZen / Navicat Premium Lite + DBeaver），新买断工具没有价差可打；且与 plainsight「大文件只读」叙事相邻。→ 必须用「5000 万行流式 + 就地编辑」拉开，不能做通用客户端。
- **失效标志**：DBeaver/TablePlus 修好流式；免费客户端补上大结果集；30 天内找不到 ≥5 个预付用户；MCP 直连数据库成为主流。

### 卡 2 · 可信选片台（域3）

- **需求**：婚礼/活动摄影师从 3000–5000 张 RAW 选几百张；现有 AI 选片不被信任，仍要逐张复核。
- **凑合证据**：Sagnik 2026-09-27（4000 帧人工 90 分钟–4 小时；AI 误判运动模糊/剪影/唯一戒指交换；第二机位时钟差 7 分钟）；Jessica Whitaker 2026-09-07（「culling sucks」；Aftershoot 4000 张 1.5 小时）；Shotkit 2025-11-17；Photodotedit 2026-07-02（3000 张人工选片 2–4 小时）。
- **付费**：Aftershoot/Narrative $120–180/年；PhotoCull（BOOTH）Pro ¥1,980 买断；imagic $10（未验证）。
- **Gate 1**：窄过（B+C）——可解释评分、关键瞬间保护、XMP 安全写回、撤销、旧电脑性能；客户照片是责任资产。
- **风险**：Adobe Lightroom Assisted Culling 2026-06 GA（二手来源，未验证）→ 系统吸收；价格天花板 $10–30；闭眼/人脸模型商业许可；旧笔记本性能；摄影人群分散。
- **失效标志**：Lightroom 内置够用；关键瞬间误杀 >10%；5000 张 >30 分钟；无合规模型可再分发。

### 卡 3 · PDF/UA 无障碍修复工作台（域5）

- **需求**：把扫描件/复杂 PDF 的标签树、阅读顺序、表格结构、Alt 文本修到能过 PAC/veraPDF，而不是在 Acrobat 里一页页重标。
- **凑合证据**：Microsoft Q&A 2025-12-23（1200 页文档只能手工改标签）；Adobe UserVoice 2026-04-16（「Auto tagging sucks」；政府机构赶 ADA Title II）；CHI 2025-04-25 论文（自动标签不够，需逐步人工修复）；Allyant 2025-02-18（EAA 2025-06-28 截止，百万页级修复服务）。
- **付费**：PDFix Desktop Pro €350/用户/年（$599），Enterprise €1,000/年（2026-10-20 实抓）；CommonLook 约 $760/许可/年（未验证）；Allyant 按页收费。
- **Gate 1**：活（B+C）——可视化结构树 + 阅读顺序 + 表格单元格 + 批量 Alt + PAC/veraPDF 报告；用户多为非开发者，agent 替代压力低。核心是「自动初标之后的修复/核对」，不是自动标签本身。
- **风险**：PDFix 出永久买断；Adobe 自动标签接近 PDF/UA；B2B 采购门槛；3 个月做不出可演示 MVP；单页工时降不到 30%。
- **失效标志**：PDFix 永久授权或补 CJK；Adobe 捆绑合规；免费 OpenDataLoader+veraPDF 被接受；90 天拿不到 10 个付费试点。

### 卡 4 · Windows 文件版本时间轴（域7）

- **需求**：本地文件夹的「撤销键」——覆盖保存/误删/改坏后可回退；File History 已被微软判 legacy。
- **凑合证据**：Microsoft Q&A 2024-01（官方建议换第三方）；2025-05 长路径静默跳过 18,000 文件；KB5124008（2026-09-08）再次炸掉 File History；Macrium Reflect 8 EOL 2025-12-31/2026-02-27；Duplicati #6110/#6553 恢复库失败；中文「最终版_v3」仪式。
- **付费**：Macrium Reflect Home $69.95 终身（前代价）、EaseUS $59.95、AOMEI $69.95；BackUp Xplorer ~$39；FileLog $19.95。
- **Gate 1**：活（A+B+C）——USN 变更监听、崩溃安全、OneDrive 占位符、长路径、ACL、块级去重、时间轴 UI、签名安装包、杀软误报；文件安全是信任品类。
- **风险**：**免费替代密度全农场最高**（Home Backup & Restore、FileHistoryClone、FolderRewind、Kopia、Restic、Veeam Agent Free、Hasleo）；微软把用户往 OneDrive 赶；存储占用投诉。
- **失效标志**：任一免费替代做到「中文+零配置+Explorer 右键+商店」；Windows 12 恢复本地版本历史；90 天陌生付费 0；30 天留存 <20%。

### 卡 5 · 可验证的本地整机备份（域10）

- **需求**：买断、无云、无账号、无到期锁的整机镜像备份，并且能证明它能还原。
- **凑合证据**：Deskmodder 2025-11-17（Hasleo 换盘还原两次失败、无日志，转 EaseUS 成功）；Hasleo 官方论坛 2025-10-30/11-22/11-24（到期锁、企业限制，「time to say goodbye」）；Macrium Reflect 8 EOL 2026-02-27、Reflect X 只卖年费；Microsoft Q&A 2026-06-13（Win11 Backup 不认外接盘）。
- **付费**：Macrium Trustpilot 4.4/4,368（聚合，未直抓）；EaseUS $59.95；Hasleo $29.95；AOMEI 终身 156 评/4.7。
- **Gate 1**：活（B+C）——VSS、WinPE、BitLocker、NVMe、Secure Boot、ARM64、换盘启动；「可验证还原」是信任入口。
- **风险**：信任是主产品；Hasleo 修好即关窗；微软云优先但可能加回本地镜像；**单人 6–12 个月**，范围过大；买断与长期兼容冲突。

- **需求**：通知一划掉/重启就没了，系统没有可搜索的长期归档。
- **凑合证据**：ComputerBase 2025-07-17（Win11 通知历史为空）；Alomware 2026-02-08（付费 Notification Logger 仍不满）；ElevenForum #22390（日期未验证）。

- **Gate 2**：**边缘未满**——3 个 URL，仅 2 个带日期。

### Wave 1 跨域结论

1. **卡集中在「持续状态 + 本地数据 + 信任/责任」**：数据库结果集、文件时间轴、整机备份、PDF/UA 修复、选片复核——都不是一次转换，而是工作流/资产/责任。
2. **死因高度一致**：一次转换（音视频、数据清洗、格式转换）、免费 OSS 10 万星（网络、系统）、系统吸收（剪贴板/窗口/通知/加密）。
3. **最强红队来自另一个域**：域6 用「免费 Rust DB 客户端成潮」正面挑战域1 的卡——合成时必须保留这条攻击。
4. **分发仍是未解乘数**：这 6 张卡的目标人群（DBA、摄影师、无障碍修复师、备份用户）与农场渠道的重合度需要逐卡估算；粗算留到调研三闸。

### 卡 7 · Windows 本地手写 PDF 批注（域11）

- **需求**：Surface/二合一用户要一支笔在 PDF 上稳定地写、划、选、擦、导出。
- **凑合证据**：Zotero 论坛 118047（2024-09-18，Surface 笔/指不分、无撤销）、117833（2024-09-12）、118744（2024-10-14，Surface Pen 高亮卡数秒）；Xournal++ #7815（2026-10-06，Win11 25H2 三周崩 5 次、90MB PDF 3.5 分钟崩）、#7542（2026-06-17，待机恢复笔迹失效）；知乎 2024-03-12（Drawboard 订阅吃相，用户钉旧版 6.35.6）。
- **付费**：Drawboard Store 4.6/990 评分，Pro 约 $83.92/年；PDF Annotator $79.95 永久授权（1996–2026 仍在售，买页客户自白）。
- **Gate 1**：活（B）——压感/笔指分离/掌托/延迟/PDF 坐标变换/注释层导出，全是硬件与状态机调试。
- **风险**：Edge/OneNote/Journal 12 个月内补上；Drawboard 降价；Xournal++ 修好崩溃；Windows 手写平板存量小；**必须真实 MPP/Wacom 设备验证**。
- **失效标志**：系统吸收；Drawboard ≤$49 永久；Xournal++ 修好；目标用户实际都在 iPad。

### 卡 8 · Windows 标签设计打印器（域17，条件）

- **需求**：小商家/小仓库把 Excel 商品、资产、价签数据批量打成标签。
- **凑合证据**：filament-db PR #487（2026-05-31，自建 Brother 标签打印）、#1042（2026-07-29，自建 TSPL 传输）、netprinter #10（2026-10-11，TSPL/GAP 缺失）；labelle 191★（2026-10-16 仍在更）。
- **付费**：LabelJoy Business $379 永久 / Enterprise $1,799（定价页，无公开销量）；易标签免费/专业版分层。
- **Gate 1**：活（B+C）——打印校准、驱动/纸张差异、字体度量、条码合规。
- **Gate 2**：**弱**——证据偏技术用户自建，缺小商家「Excel + 打印机自带软件凑合」的直接行为源。
- **风险**：免费 labelle/ZPL-Label-Designer/ZPLab 密集；只有标价没有销量；兼容矩阵无底洞；厂商捆绑免费软件。
- **失效标志**：免费项目补齐 WYSIWYG + Excel 绑定；prespec 拿不到 ≥3 条小商家付费/求推荐；兼容维护 > 每周 5 小时。

### 卡 9 · 视频素材索引/复用工作台（域20，弱）

- **需求**：10–30TB 原始视频，命名混乱、跨次交接后找片段靠翻文件夹。
- **凑合证据**：V2EX 1104923（2025-01-14，30T 素材找半天）、1188451（2026-01-26，TB 级原片 + 代理压 10G）、1134055（2025-05-24，Excel 管几万行/图，AI 方案增量难、无后悔药）、Meta Player 开源（2026-05-07，8★）。
- **付费**：Eagle $34.95 终身（2026-10-20 抓取）；V2EX 2019 年 RMB199 入正自白；缺 2024+ 新购买自白。
- **Gate 1**：边缘——Meta Player 是单人用 AI 一个月造出的 Electron 原型；PromptClip/Iterlay 证明 agent 正在逼近「整理」。
- **Gate 2**：过（4 条 V2EX，但单社区）。
- **Gate 3**：弱（邻近 Eagle 付过钱，不是本形态）。
- **风险**：BillFish/Pixcall/Meta Player 免费；Eagle $34.95 十年打磨；专业剪辑师 Mac 占比高；30TB 性能。
- **失效标志**：免费在位者覆盖代理+多标签+台词检索；访谈 6/10 说够用；>60% 用 macOS。

### Wave 2 跨域结论

1. **域 12/14/15/16/18/19 整域关闭**：一次转换、SaaS/后端、移动端错位、免费 OSS、系统吸收、服务而非软件。
2. **域 13 的唯一活口（进销存）卡在 Gate 3**：有年费疲劳、免费版限单据、到期锁数据，但拿不到买断销量/评分硬数。
3. **域 11 的手写 PDF 批注是 Wave 2 最强卡**：需求、付费、agent 替代三条都硬；但需要真实笔设备验证，且市场天花板在 Surface/二合一。
4. **域 17 标签打印器 Gate 2 未闭合**，域 20 视频素材台 Gate 3 弱——都不能直接开枪。

### 100 泳道的结构性读数

1. **「一次转换/生成/搬运」仍然是最大杀手**：Wave 1 的音视频、数据清洗、格式转换，Wave 2 的写作、内容再利用、Prompt 管理，全部命中。
2. **免费 OSS 的星级已经从「替代品」变成「地板」**：10 万星级的 LocalSend/Clash/RustDesk/Ollama/RAGFlow 把整个域的价格锚钉在 0。
3. **系统吸收仍在继续**：剪贴板、通知、窗口、加密、字幕、转录、放大镜——Windows 内置或 PowerToys 一路补。
4. **活下来的 9 张卡有共同形状**：**持续状态 + 本地数据 + 责任/信任 + 非一次性输出**。这正好是 agent 最难替代、免费工具最难做好的那一层。
5. **但这 9 张卡的分布仍然薄**：目标人群是 DBA、摄影师、无障碍修复师、备份用户、Surface 用户、小商家、视频创作者——与农场现有渠道（GitHub/小众软件/MS Store/技术社区）的重合度，逐卡都要重新算。

### 裁决建议

- **没有一张卡能在「渠道可见流量」上明显跑赢历史产品**；PDF/UA 和 DB 工作台的单价更高，但工时也翻倍，且 B2B/开发者渠道需要新的分发能力。
- 若按「钱 + 缓冲地带」的目标，**最值得先验证的是 PDF/UA 修复台**（付费意愿最高、合规驱动、买断位空着），但它需要 B2B 访谈，不是写代码。
- 若按「引擎复用 + 农场现有渠道」的目标，**大结果集 DB 工作台**最顺（logfile/plainsight 的快速网格肌肉直接复用），但正面撞免费 Rust 客户端。
- 若按「最快做出可演示成品」的目标，**文件版本时间轴**最轻（USN + 去重 + 时间轴），但免费替代最多、单价最低。

### 下一步选项

- **A · 对一张卡做廉价探针**（假门/访谈/预售），读数过线再 spec。
- **B · 转行为推断轮**（用户原指令的 fallback）：100 泳道证明「现成产品」已被扫穿，下一步从现象推断新的交互方式。
- **C · 停选型**，把带宽转分发/收银台/log v1.x。
